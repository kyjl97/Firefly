把 Agnes 接进 Codex

我自然接入了被打入凡间，已经生活不能自理的 Codex，之前介绍过，API 登录，最佳伴侣就是 Codex++ 这个插件。

官方也提供了目前市面上了流行的各个 agnet 工具的接入方法：

agnes-ai.com/doc/overview

对着找自己的教程就行，其实你直接丢文档过去给你的 agent 去装也行。

第一步：注册账号，拿到 API Key

打开官网 agnes-ai.com，选择「API 平台」注册登录进去。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

登录成功后，左侧菜单找到「API 密钥」，点「创建新的密钥」，后面要用。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

第二步：下载并安装 Codex++

这是一个配套的管理工具，配置完成后即可在 Codex 中使用 Agnes 2.0 模型，无需登录 GPT 账号。

下载地址：

github.com/BigPizzaV3/CodexPlusPlus/releases/latest

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

根据自己的系统选对应版本，下载完正常安装就行。

第三步：配置 Agnes 供应商

打开 Codex++ 管理工具，进左侧菜单 →「供应商配置」→「添加供应商」。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

按下面信息填：

名称：Agnes

接入模式：纯 API

测试模型：agnes-2.0-flash

Base URL：https://apihub.agnes-ai.com/v1

Key：填你刚才复制的 API Key

上游协议：选择 Chat Completions

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

填完点「保存」，然后在供应商列表里找到 Agnes，点「使用」，

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

再回到概览页面，点右上角的重启按钮。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

第四步：验证配置是否成功

重启之后，在 Codex 上新建一个会话，随便输一句：你好，请介绍一下你自己。

Codex 正常回复了？那就配成功了。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

整个流程就大概几分钟，还是挺简单的。

实测：真的能用吗？

装完之后，这时候虽然显示接入的是 agnes-2.0 flash，但是不需要你再接入同系列的生图和视频模型，只需要装个 skill，就可以实现模型路由功能，自动去调配对应模型完成任务。

github.com/Yacey/agnes-ai-generation-skill

更有意思的是技术路子，Agnes 用的是多模型集群加智能路由架构，把一个任务拆成子任务，分给各自专精的小模型并行处理，推理成本做到了单模型架构的 1/10，速度反而更快。

结语

Token 花费越来越贵这件事，不是今天才开始的。

大模型的调用成本一直在涨，很多工具的免费额度越来越少，背后的商业逻辑越来越清晰，先用免费把你留住，再慢慢收。

Agnes 喊永久免费，说实话我不知道这句话能撑多久。但至少在现在这个时间点，管它那么多，只管蹬就是。

它不需要替代你的主力工具，主力工具该用就用，该付费就付费。

但你的主力工具也有趴窝的时候，就像我的 Codex，因为一个手机号验证就直接给我堵在门外好几天。这种时候，手边有一个能顶上去的备选，是真的有用。

响应速度不慢，社群支持及时，接入门槛低，覆盖文本、图像、视频三个场景。

随手可用，挺香的。

这次 Codex 登不上的那几天，我没少抓狂。但因为这段空窗期，反而发现了 Agnes 这个东西。

这绝对是一个意外惊喜，快冲吧，伙计们！
