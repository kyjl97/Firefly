### **🔧 核心功能概述**

**飞书MCP**是飞书文档集成AI能力的扩展功能，通过配置企业自建应用实现文档自动化处理、数据抓取与消息推送等高级功能。用户反馈其为”AI+飞书文档的强大组合”，配置完成后可显著提升工作效率。

### **📋 配置流程详解**

#### **一、前期准备阶段**

1. **访问飞书开发者后台**：通过`open.feishu.cn`进入企业自建应用创建界面
2. **创建应用**：输入应用名称（如”飞书MCP Demo”）并完成基础信息配置
3. **添加机器人能力**：在应用管理界面中启用”机器人”功能模块

#### **二、权限配置核心步骤**

| 权限类别 | 需开通权限项 | 应用场景 |
| :-- | :-- | :-- |
| **云文档权限** | 全选文档相关权限 | 文档创建/编辑/管理 |
| **消息权限** | 消息发送与群组管理 | 自动发送群消息 |
| **多维表格权限** | 表格数据读写权限 | 数据整理与分析 |
| **用户身份权限** | 用户信息获取权限 | 操作身份认证 |

#### **三、应用发布与认证**

1. **创建应用版本**：填写版本号（如v1.0.0）并提交企业管理员审批
2. **获取凭证信息**：审批通过后在”凭证与基础信息”中获取`App ID`和`App Secret`
3. **安全设置配置**：添加重定向URL（如`http://localhost:3000/callback`）

#### **四、本地环境配置**

1. **安装依赖**：确保已安装Node.js环境
2. **登录认证**：执行命令行工具登录`openapi mcp`，替换`your fid`和`app secret`
3. **集成Cloud Code**：通过`cloud mcp add`命令添加MCP配置，格式示例： `bash cloud mcp add --name lock_mcp '{"app_id":"xxx","app_secret":"xxx"}' --scope user` \### **🚀 功能应用场景** #### **一、文档自动化** - **案例**：通过命令创建指定标题的飞书文档（如”如何赢回前任的心”） - **实现方式**：`cloud mcp run "帮我创建飞书文档，标题是[标题内容]"` #### **二、数据抓取与表格生成** - **案例**：自动抓取”秋之二零四六”最新20条笔记数据并整理至多维表格 - **优势**：支持自定义数据维度（点赞数、浏览量、收藏转发等） #### **三、消息自动推送** - **案例**：向指定群组（如”相亲相爱一家人”）发送预设消息 - **权限要求**：需额外开通”消息发送权限”和”用户ID获取权限” ### **⚠️ 常见问题与解决方案** | 问题现象 | 原因分析 | 解决方法 | | :——- | :——- | :——- | | 登录失败提示”redirect url不合法” | 未配置重定向URL | 在应用安全设置中添加`http://localhost:3000/callback` | | 消息发送提示”权限不足” | 未开通消息相关权限 | 通过错误提示链接直接跳转开通对应权限 | | 命令执行无响应 | App ID或Secret错误 | 重新获取并替换凭证信息 | ### **💡 关键洞察** 1. **配置复杂度**：飞书MCP需8项准备工作+多步骤权限配置，较同类产品复杂，但提供更精细的权限控制 2. **企业级特性**：需管理员审批流程，适合企业环境下的安全管控 3. **AI集成潜力**：当前已实现基础自动化，未来可扩展更复杂的文档分析与内容生成功能 4. **用户体验优化**：权限缺失时提供直达配置页面的链接，降低问题排查难度
