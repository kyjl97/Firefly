### **🔧 产品核心定位与优势**

**产品定义**  
New Type OS是一款**定制化AI内容创作与知识管理系统**，专为知识消化和内容产出设计，定位为Co coded的升级替代品。开发者日常60%时间使用该工具，已通过其产出数万字内容。
**核心优势**
- **定制化设计**：针对内容创作场景优化，性能优于通用工具
- **多Agent架构**：内置8个专业Agent，分工明确
- **灵活模型配置**：支持多模型供应商接入，平衡性能与成本
- **生态整合**：可与微信、Open Cloud等外部工具联动

### **📥 安装与配置指南**

#### **一、基础安装步骤**

1. **核心命令**：终端输入 `N PM install`（原文表述，标准应为`npm install`），几秒即可完成  
2. **前置依赖**：需预先安装**Node.js**（官网下载）  
3. **启动方式**：安装完成后输入 `NT`（New Type缩写）启动系统  

#### **二、关键配置流程**

| 配置项 | 操作方法 | 核心作用 |
| :-- | :-- | :-- |
| **连接模型供应商** | 输入 `/connect` 选择供应商（如OpenAI、质朴mini max、GitHub Copilot） | 建立AI能力底座，支持API按用量付费或订阅模式 |
| **Agent模型分配** | 输入 `/aj models` 为8个Agent配置适合模型 | 实现资源优化，避免高端模型滥用 |

### **💻 使用场景与操作指南**

#### **一、推荐运行环境**

- **终端选择**：优先使用**Z终端**（支持TUI渲染、多任务处理、界面美观）  
- **替代方案**：系统自带终端或VS Code（可能存在渲染卡顿问题）  

#### **二、项目初始化流程**

1. **知识库构建**：输入 `/initt -D`
	- 功能：AI扫描整个内容仓库，生成`knowledge.md`文档  
	- 价值：让系统全面了解项目背景  
2. **人格定义**：输入 `/initt sor`
	- 功能：创建`sol.md`文档，定义Chief Agent的**表人格**（底层人格不可更改）  
	- 类比：类似Open Cloud的性格定义功能  

#### **三、核心功能模块**

- **多Agent协作**：用户仅需与**Chief Agent**对话，系统自动拆解任务并分配给专业Agent  
- **技能增强（Skills）**：内置专业能力模块（如`super analyst`用于深度分析）  
- **MCP功能**：未详细说明，推测为多任务协调协议  

#### **四、高级扩展功能**

| 功能 | 配置命令 | 应用场景 |
| :-- | :-- | :-- |
| **微信集成** | `nt wechat setup`（扫码绑定）+ `nt wechat start` | 实现微信消息互通 |
| **外部Agent调用** | `ntit`（注入Open Cloud技能） | 与Open Cloud等工具联动 |
