### **📢 招募核心信息（基础要求）**

**岗位性质**
- **全职/兼职均可**：兼职按单条视频结算；全职需先以兼职形式完成3-5条视频，进行双向选择。
- **工作地点**：无限制，支持网络协作（素材网络传输、线上沟通），仅需按时交付成果。

### **🎬 内容剪辑分类（技术方向）**

#### **(一) 纯流水账式剪辑**

- **核心特点**：以实拍原声原画为主，无后期配音，保留素材中有梗内容。
- **后期处理**：通过音乐、花字、特效增强节奏感和趣味性。
- **参考案例**：挑战类内容（如“挑战去四川偷甘蔗”“挑战在北京当一天外卖员”“挑战四十八小时找到武磊”）及过往段子类视频。
- **参考账号**：完美婆娘老师、崔丁老师。

#### **(二) 配音解说式叙事剪辑**

- **核心特点**：结合前期实拍素材与后期配音，打乱原始素材顺序，按新逻辑二次叙事。
- **目标效果**：提升视频节奏密度、丰富看点、明确观点表达。
- **参考案例**：“人生第一次买房”“恋爱八年第一次去女朋友家”“探访曹县棺材产业”。
- **参考账号**：李娃娃老师、张毅老师。

### **🎯 视频内容类型（创作方向）**

| 类型 | 核心描述 |
| :-- | :-- |
| **体验和挑战类** | 挑战生理/物理难度或伦理秩序难度的命题；体验鲜为人知的行业、人生或新鲜事 |
| **行为艺术类** | 通过组织活动、街头陌生人互动、策展等形式，拍摄具有治愈、反思或反讽意味的内容 |

### **✍️ 剪辑工作内容（职责范围）**

1. **素材处理**：高效率筛选整理素材。
2. **沟通协作**：与创作者沟通，确定剪辑脚本。
3. **制作流程**：完成粗剪、精剪修改，最终定稿成片。
4. **备注**：创作者会提供细化的素材整理和剪辑脚本，但剪辑需具备独立完成全流程的能力。

### **💪 期望能力要求（核心素养）**

1. **专业能力**：优秀的叙事能力、理解沟通能力、高效率工作态度。
2. **网感要求**：具备“网感”，包括但不限于热门BGM风格，冷门邪门网感亦可。
3. **知识储备**：广泛涉猎独立纪录片、艺术片、广告电影、行为艺术等领域，要求涉猎越广越好。
4. **成果导向**：能够将创意（idea）转化为最终视频文件（MP4或MOV格式），注重实际作品呈现。

### **📝 补充细节**

- **双向选择机制**：全职岗位需通过兼职阶段（3-5条视频）验证能力，确保双方匹配度。
- **创作理念**：强调从创意到最终视频文件的全流程落地能力，重视剪辑师的独立创作和表达。
