大家好，我是冷逸。

硅谷最近兴起了一种“Tokenmaxxing”（Token刷榜）文化。

Meta内部搞了个Claudeonomics榜，专门追踪员工的Token消耗量，30天内全公司消耗超60万亿Token；黄仁勋直说，如果年薪50万美元的工程师一年没有消耗25万美元的Token，他会“深感不安”；还有OpenAI工程师晒账单，一周两千多亿Token，算下来几万美元就这么没了。

说实话，第一次看到这些数字，我是懵的。一个月烧掉几万美元的Token，这是什么家庭条件？后来仔细研究了一下他们的用法，发现这些人不是在浪费，而是在用Token堆出AI的上限——让AI反复改、反复跑、反复试错，直到拿到真正可用的结果。

这种用法确实奢侈，但思路本身没有问题。

上周末我在星巴克做了一场Vibe coding的线下分享，来了七八十号AI coding的发烧友。有人问我，怎么快速建立coding手感？我说了一句话：“要练coding手感，先把自己的日Token消耗量拉到亿级再说。”

![[images/28e05b2cfba02c32e1e62bed1ba3692d_MD5.jpg]]

不是在凡尔赛。我的意思是，如果你每天连几百万Token都没烧过，一直在用免费额度的AI Chat，那你对AI coding的理解大概率还停在“帮我写个网页”这个层面。

当你真的放手去用，让AI搭架构、写应用、跑测试、自己修bug——你才会发现，AI能做的比你以为的多得多，但它的坑，也比你以为的深得多。而这些认知，光靠看教程、刷视频是学不来的，必须自己真金白银地烧过Token，踩过坑，才能长进肌肉里。

但问题是，不是每个人都有Meta工程师的预算。一个月几万美元的Token账单，对大多数人来说就是天方夜谭。

所以我看到讯飞星辰最近推出的Astron Coding Plan，第一反应是：这价格，认真的吗？

最低订阅价只要3.9元。注意，不是美元，是人民币。不是一天，是一个月。

这个价格低到什么程度呢？我算了一下，你在星巴克买一杯最普通的美式，差不多能订三个月还富余。你中午吃一碗重庆小面，订完Plan还能再买杯蜜雪冰城。这个门槛，几乎等于没有。

当然，便宜不是全部。定价再低，东西不会用也是白搭。

所以今天这篇文章，我想跟你跟你聊聊具体的上手体验，如何接入到Claude Code、Codex、OpenClaw这些Agent里，与其他Coding Plan有何区别，最后说说我对讯飞这套打法的判断。

![[images/b8a893de63891feacb21e52b69d1715c_MD5.jpg]]

一手体验

1）如何订阅？

订阅比较简单，直接前往这个页面，选择需要的Plan即可。

![[images/5e6cb05496c9d4bffc4ba5438e98fe07_MD5.png]]

入口：https://maas.xfyun.cn/modelSquare?ch=MaaS-xbkol-wy

你可以配合着我的邀请码一起使用：MAAS-E2C9B7F3，这样你我都能得到等额的礼品卡奖励，可以用来购买平台内的API服务。

这三个Plan，如果想尝新，可以选择无忧版，3.9一个月，可以体验讯飞星火自家的X2-Flash以及Qwen3.6 35B、Qwen3.6 35B、GLM4.7-Flash这几个小模型。

注意，请求次数是无限的。这意味着，你可以使劲造，拿来做一些快速开发、重复工作、文档处理、本地脚本等任务，非常好使。

如果是专注编程和长程任务，推荐订阅专业版和高效版，像GLM-5.1、K2.5、Qwen 3.6、DeepSeek V3.2、Spark X2这些国内的主流模型都可以体验。

这2个Plan在模型支持上是一样的，只是请求次数不一样。专业版是每5小时1200次，高效版是每5小时6000次，是专业版的5倍。这个根据自己的需求来，高频开发就上高效版，中频就上专业版。

订阅后返回管理后台，它会自动生成一个Coding Plan的标签模块。

![[images/613db3a34bd993a8d502c71f286655bd_MD5.png]]

这里面，讯飞星辰把套餐情况、用量统计和关键配置信息都放在了一个地方，非常方便。

API Key、model id、openai\_url和anthropic\_url都有，它全部帮你配置好了，只需要点一下就可以复制。

如果你是在Codex、OpenClaw、Cursor里用，url用OpenAI格式的；如果你是在Claude Code里用，则用Anthropic格式的。

model id统一填astron-code-latest，这是一个智能路由的模型名。

需要切换模型时，直接在后台点“配置模型”，选择模型后即可，1-3分钟后生效。

![[images/dc1bd999210febc96a0e67cba5fdc86f_MD5.gif]]

这点非常方便，不用你到CC-Switch这类第三方工具上手动切。

如果不想付费的话，讯飞星辰的模型集市也有很多免费模型可以体验。比如Qwen-3.5-35B和Qwen-3.6-35B这两款小模型，参数虽小但智能不减，可享受7-30天的免费高并发。

![[images/cff02def84b107f4c1875d238d1b92bf_MD5.png]]

2）如何接入？

订阅了Plan后如何接入到各个Agent里，我们分开讲。

先看Claude Code。

Windows用户，打开cmd，输入这段指令：

```
setx ANTHROPIC_BASE_URL "https://maas-coding-api.cn-huabei-1.xf-yun.com/anthropic"
setx ANTHROPIC_AUTH_TOKEN "你的API Key"
setx ANTHROPIC_MODEL "astron-code-latest"
```

macOS用户，在终端输入这段指令：

```
export ANTHROPIC_BASE_URL=https://maas-coding-api.cn-huabei-1.xf-yun.com/anthropic
export ANTHROPIC_AUTH_TOKEN=你的api key
export ANTHROPIC_MODEL=astron-code-latest
```

执行指令后，关掉终端，重新再打开一个，随便问几句，看它吐不吐token。能正常吐token，就代表配置成功。

![[images/bddb49e6aeb23df4bdb8a8923fb129d5_MD5.png]]

这里分享大家一个技巧，如果你不希望Claude Code老爱说英文，你可以在C盘Administrator文件夹下找到CLAUDE.md文件，在里面添加这样一句指令：

```
## language
- 请始终使用简体中文与我对话。
```

![[images/424123ff88231078baff7ca005dbc9c7_MD5.png]]

然后是OpenClaw，这个就非常简单了，直接跟你的龙虾说：

> 这是API Key：xxxx，url：xxxx，model id：xxxx，请帮我重新配置。

最后是Codex，最近很多人都在疯狂安利的Agent神器，不仅编程开发非常方便，日常办公也很受用。

但Codex本身并不支持外接模型，所以我们需要手动配置一下。

我先以Windows为例给大家讲解，这是最难的，macOS反而比较简单。

首先，我们需要装Python环境，3代版本以上。

![[images/6b2ac0defbb91392d3d14222739331cf_MD5.png]]

入口：www.python.org/downloads

如果你已经装过了​（装过Claude Code、TRAE，基本都装了Python）​，可以在终端里输入这段命令查询版本号。

```
python --version
```

能正常显示版本号，就代表已经装过了。

![[images/1e69672fd379f284aeb805997492ff93_MD5.png]]

然后，安装一下CC Switch。

入口：https://github.com/farion1231/cc-switch/releases/tag/v3.15.0

拖到最底部，找到Assets，Windows建议下载CC-Switch-v3.15.0-Windows.msi这个安装包，可以写入注册表，方便Agent调用，也能自动更新。

![[images/346cb6d564310a3655d9faa67c430a64_MD5.png]]

以及，你需要先提前安装Codex。

![[images/447e0b7aa218d1394168c3b86d83c777_MD5.png]]

入口：https://openai.com/zh-Hans-CN/codex/get-started/

这些准备工作都做好后，我们打开PowerShell，输入这段命令：

```
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://gitee.com/kangarooking/xfyun-codex-adapter/raw/main/install.ps1 | iex"
```

这是好朋友@袋鼠帝 写的一个自动化脚本，输入后会在本地执行命令，然后根据提示输入Astron Coding Plan的API Key就可以了。

![[images/572ea4f05720342feb0ad87c9dc88a8c_MD5.png]]

输入API Key后，会自动弹出CC Switch，显示已配置成功。

![[images/ca5d477ac1794a1c58af9524d53c758d_MD5.png]]

然后再重启Codex，随便问一句，可以看到讯飞的模型已接入成功。

![[images/dc73c8aa22f0f28b8d541b284e7315bf_MD5.png]]

卸载指令是：

```
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://gitee.com/kangarooking/xfyun-codex-adapter/raw/main/uninstall.ps1 | iex"
```

如果你是macOS，就不需要装Python，直接在终端执行这段脚本：

```
curl -fsSL https://gitee.com/kangarooking/xfyun-codex-adapter/raw/main/install.sh | bash
```

卸载指令：

```
curl -fsSL https://gitee.com/kangarooking/xfyun-codex-adapter/raw/main/uninstall.sh | bash
```

3）如何选型？

Astron coding plan提供了很多的模型。

![[images/424f3e47f4cd9451c45332143c32ce91_MD5.png]]

追求速度，带Flash的几个版本都可以选择，比如讯飞自家的Spark-X2-Flash、GLM-4.7-Flash和Qwen3.6-35B-A3B。

任务带有视觉识别，推荐Qwen3.6-35B-A3B和K2.5。

给龙虾使用，推荐MiniMax-M2.5，擅长长程任务。

写代码，推荐GLM-5.1、K2.5、M2.5和Qwen3-Coder-Next。

写作类任务，推荐DeepSeek-V3.2、Qwen3.5-397B-A17B。

如果你要在这几个模型里挑选最佳，那无疑是glm-5.1，就是资源有点紧张。

比如我用Codex + glm-5.1制作了一个3D版的金门大桥。

![[images/da6ca45b50b10a7d71537ea62973c53c_MD5.png]]

One shot就能出很好的效果。

![[images/226eb9c66f4c8e018c7a1f85b2cb78aa_MD5.gif]]

同样Prompt，我在DeepSeek V4那边就跑不好这个case。

![[images/831913404078f641f69b787cc00ee33b_MD5.png]]

这也从侧面证明，讯飞Astron Coding Plan的glm-5.1绝对正宗，质量在线。

![[images/95a1738c1c831318d2b81db55bb13383_MD5.jpg]]

写在最后

体验下来，讯飞星辰这波Coding Plan挺猛的。

3.9元就能让你实现Token无限，体验一把老美“Tokenmaxxing”的爽感，这还要什么自行车。

当算力不再成为阻碍，剩下的就看你的创意和想象力了。

如果一开始做不出来好的产品，也没有关系，先练你的Coding手感。
