# Home Console — 产品需求文档 (PRD)

## 一、项目概述

**产品名称**: Home Console（首页控制台）  
**类型**: Obsidian 插件  
**目标**: 为内容创作者打造一个以**内容流水线**为核心的仪表盘，一键触发 AI 技能，掌控从输入到发布的全流程。

### 核心理念

这不是一个通用的任务管理器，而是一个**内容生产控制台**。围绕用户的四层内容体系（输入 → 知识库 → 文章 → 索引），将所有操作浓缩到一个面板。

### 与现有 Dashboard 插件的差异

| 维度 | 通用 Dashboard | Home Console |
|------|---------------|-------------|
| 核心单位 | 任务/待办 | 文章/素材/知识页面 |
| 数据源 | checkbox | frontmatter + 目录结构 + Dataview |
| 操作方式 | 只读展示 | 点击按钮触发 AI Skill 执行 |
| 适配体系 | 通用 GTD | 四层内容体系 (01-输入→Library→posts→wiki) |

---

## 二、用户画像

- **身份**: 个人内容创作者，维护 Astro 博客 + Obsidian 知识库
- **日常工作流**: 剪藏素材 → 编译到知识库 → 选题 → 写作 → 去 AI 味 → 配图 → 发布 → 同步索引
- **AI 工具**: Claude Code CLI，配置了 13+ 个斜杠命令（Skill）
- **痛点**: 每次执行 Skill 需要手动输入命令，缺乏全局视野，不知道系统健康状况

---

## 三、功能需求

### F1: 顶部统计栏（StatsBar）

实时显示内容系统的关键指标。

| 统计项 | 图标 | 数据来源 | 计算逻辑 |
|--------|------|---------|---------|
| 收件箱 | 📥 | `01-输入/` 下所有子目录 | 未归档文件数（排除 archive/ 和 07-Daily/） |
| 草稿 | 📝 | `posts/` 全目录 | `draft: true` 的文章数 |
| 本周发布 | ✅ | `posts/` 全目录 | `published` 在本周且 `draft: false` |
| Library | 📚 | `Library/` 四个子目录 | 总页面数 (concepts + entities + sources + syntheses) |
| 死链 | 🔗 | `wiki/` 全目录 | 引用不存在文件的 wikilink 数量 |

**交互**: 点击统计卡片可跳转到对应的 Tab 面板。

### F2: Skill 按钮栏（SkillBar）

三行按钮，点击即在 Obsidian Terminal 中执行对应的 Claude CLI 命令。

**第一行 — 每日运转**: 任务、想法、选题、灵感、日志、每日开场  
**第二行 — 知识管理**: 笔记分诊、收件箱归档、查知识库、知识库体检、全量同步、索引同步、Wiki同步  
**第三行 — 内容生产**: 选题生成、写文章、写教程、引流文案、去AI味、文章配图、内容打包、热点雷达

**交互**: 点击按钮 → 打开/聚焦 Obsidian Terminal → 发送 `claude '命令'` → 终端显示执行过程。

### F3: Tab 面板（TabPanel）

四个 Tab 对应内容流水线的四个阶段：

| Tab | 对应阶段 | 展示模块 |
|-----|---------|---------|
| 📥 输入池 | 外部输入 → `01-输入/` | 收件箱列表、来源统计、编译进度 |
| 📚 知识库 | 编译输出 → `Library/` | 最新知识页面、分类分布、健康度、孤立页面 |
| ✍️ 创作台 | 写作 → `posts/` | 草稿列表、进行中的文章、分类分布 |
| 🌐 发布看板 | 索引 → `wiki/` | 已发布统计、标签云、Wiki 同步状态 |

### F4: 每日开场自动化

点击「每日开场」按钮时，自动：
1. 检查今日 Daily Note 是否存在
2. 如果不存在，基于模板创建
3. 在终端执行 `claude '$日常-每日开场'`

### Frontmatter 字段（posts/ 文章）

```yaml
title: 文章标题          # 必填，字符串
published: 2026-05-17   # 必填，YYYY-MM-DD
tags: [标签1, 标签2]     # 必填，列表
category: AIHacks        # 必填，枚举
draft: false             # 必填，布尔
pinned: false            # 可选，布尔
image: https://...       # 必填，封面图 URL
```

## 五、非功能需求

| 需求 | 说明 |
|------|------|
| 性能 | 统计数据缓存，文件变化时增量更新，避免全量扫描 |
| 暗色主题 | 默认暗色，与 Obsidian 暗色主题融合 |
| 可配置 | Skill 按钮可自定义显示/隐藏，目录路径可配置 |
| 兼容性 | Obsidian 1.5.0+，桌面端（不考虑移动端，因为依赖终端） |
| 终端依赖 | 需要安装 Obsidian Terminal 类插件 |
