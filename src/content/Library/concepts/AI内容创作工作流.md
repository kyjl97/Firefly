## 定义

AI 内容创作工作流是利用 AI 工具（Claude Code、Obsidian、宝玉 Skills、New Type OS 等）构建从素材收集、知识管理、内容生成到排版发布的全自动化流程，核心是让 AI 系统越用越懂用户，实现可自我进化的创作系统。

## 要点

- **Obsidian + Claude Code 方案**：五步流程（锁定形象 → 剧情分解 → 文件管理 → 中央工作流说明书 → 专属技能），系统自我进化（达标率从 50% 提升至 70%，成本从 30 刀降至 10 刀）
- **New Type OS 方案**：多 Agent 架构，用户仅与 Chief Agent 对话，系统自动拆解任务分配给 8 个专业 Agent
- **AI 视频方案**：Gemini 2.5 Pro（导演）+ Google Flow（视频生成）+ Veo3（提示词），全链路自动化
- **版本控制必备**：AI 批量处理文件能力越强，越需要 Git 版本控制兜底
- **中央工作流说明书**：AI 整理所有要求创建统一说明书作为项目大脑，避免长上下文引发幻觉
- **核心价值**：把模糊需求转化为可执行流程，每次对话都在训练 AI 更懂用户
