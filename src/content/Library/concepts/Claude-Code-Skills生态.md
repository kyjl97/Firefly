## 定义

围绕 Claude Code 构建的开源 Skills 生态系统，博主和开发者将自己的方法论、工作流封装成可复用的 Skill，通过 `npx skills add` 一键安装。

## 要点

- **安装方式**：`npx skills add <owner>/<repo>` 或 `npx skills add <owner>/<repo> --skill <name>`
- **存放路径**：`.claude/skills/` 目录下
- **博主生态**：李继刚（认知工具箱）、花叔（内容 21 合 1）、苍何（配图发布全链路）、袋鼠帝（起号自动化）、卡兹克（写作 + 研究）、归藏（PPT）
- **分类覆盖**：写作、配图、PPT、视频剪辑、去 AI 味、调研、数据分析、翻译、创业、编程
- **使用建议**：别贪多（2-3 个先用）、装前看源码、保持更新、别把工具当拐杖
- **安装工具**：add-skill（Vercel Labs）可一行命令安装到多平台
- **质量差异**：有粉丝基础的博主 Skills 安全性更有保障，装前扫一眼 README 和 Issues
