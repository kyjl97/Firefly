## 定义

硅谷兴起的一种 Token 消耗文化，核心理念是通过大量消耗 Token 让 AI 反复试错、反复修改，直到拿到真正可用的结果，从而建立 AI coding 的"手感"。

## 要点

- **Meta 内部实践**：Claudeonomics 榜追踪员工 Token 消耗量，30 天全公司消耗超 60 万亿 Token
- **黄仁勋观点**：年薪 50 万美元的工程师一年没有消耗 25 万美元的 Token 会"深感不安"
- **实践建议**：先把日 Token 消耗量拉到亿级，才能真正理解 AI coding 的上限和坑
- **认知来源**：光看教程、刷视频学不来，必须真金白银烧过 Token 踩过坑
- **低成本入口**：Astron Coding Plan 3.9 元/月、Step Plan 等降低了门槛
