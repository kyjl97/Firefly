## 定义

使用多个 AI Agent 同时开发不同模块的软件开发模式，通过共享接口定义实现模块间协作，大幅提升开发效率。

## 要点

- **开发流程**：头脑风暴 → 写计划 → 并行开发
- **模块划分**：将项目拆分为无依赖关系的独立模块
- **协作机制**：通过共享的接口定义实现 Agent 间协作
- **工具支持**：Superpowers 框架提供 Dispatching Parallel Agents Skill
- **效率提升**：15 个模块可同时开工，无需串行等待
