## 定义

AI 编程工具合集，涵盖命令行 AI 助手、浏览器自动化插件和多 Agent 内容创作系统。

## 核心能力/特点

### Gemini CLI
- 谷歌推出的 AI 命令行工具，在智能化控制电脑方面有独特优势
- 支持自然语言指令完成批量处理、自动化工作流
- 10 大场景：会议纪要、图片批量处理、知识图谱生成、PPT 制作、文档转换、视频下载/剪辑、文件整理、图片处理、深度工作环境
- 协调第三方工具（Slidev、yt-dlp、ImageMagick、Pandoc、ffmpeg）的执行逻辑

### Codex Strong
- Codex 平台的浏览器自动化插件，让 AI 像人一样操作浏览器
- 通过 Crom 生成独立标签页组，与用户操作完全隔离
- 适用于重复性网页操作、企业内部系统自动化（OA/ERP 批量表单）

### New Type OS
- 定制化 AI 内容创作与知识管理系统，内置 8 个专业 Agent
- 用户仅需与 Chief Agent 对话，系统自动拆解任务分配
- 支持多模型供应商接入、微信集成、外部 Agent 调用
- `/initt -D` 扫描仓库生成知识库，`/initt sor` 定义 Agent 人格
