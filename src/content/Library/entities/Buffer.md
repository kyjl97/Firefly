## 定义
Buffer 是一款社交内容调度工具，支持全渠道发布短内容，最新开放 API 可与 Codex/Claude Code 集成。

## 核心能力/特点
- 社交内容调度与发布
- 全渠道发布短内容
- 开放 API 支持 AI agent 集成
- Buffer Publisher 技能可自动从 Codex 提取内容创意添加到 Buffer
- 支持创意库管理，方便后续创作安排
