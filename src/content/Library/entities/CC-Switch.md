## 定义

将国产模型 API 转换为 Codex 所需 Responses API 格式的桥接工具，是接入第三方 API 到 Codex 的关键中间件。

## 核心能力/特点

- 将 OpenAI 兼容 API 转换为 Codex Responses API 格式
- Windows 版本为 .msi 安装包，可写入注册表、自动更新
- GitHub 地址：`github.com/farion1231/cc-switch/releases`
- 支持配合自动化脚本一键配置（如讯飞 xfyun-codex-adapter、阶跃 stepfun-codex-adapter）
