## 定义

Craft Agent 是一款免费开源的 AI 工作工具（AI Working Tool），面向普通非程序员用户设计，官网 `agents.craft.do`，支持 Mac（M 系列/英特尔）、Windows、Linux 系统。

## 核心能力/特点

- **低门槛**：配置步骤简单，不需要命令行操作，填入 API Key 即可使用
- **全模型兼容**：支持所有主流大模型服务商（OpenAI、智谱等），纯自定义模型需手动填写 URL 和模型信息
- **并行任务**：支持同时执行多个任务，可按状态（进行中/已完成/已取消）筛选和管理
- **任务管理**：左侧功能栏 + 中间任务列表 + 右侧对话框布局，支持标签、标记完成/取消
- **技能系统**：三级存储（项目级 > 工作区级 > 全局级），支持从技能商店安装、自定义创建，安装 find_skill 后可自动查找安装其他技能
- **自动化任务**：支持定时任务、基于事件触发的任务、智能体任务
- **多种资源接入**：支持 API、MCP、本地文件夹作为任务资源
- **执行模式**：EXPLORE（仅可读）、ASK（需确认写操作）、EXECUTE（自动执行）
- **对话分享**：支持生成对话链接，他人可查看完整对话过程（含思考步骤和执行思路）
- **个性化设置**：支持个人偏好（控制输出风格）、自定义权限、快捷键、亮暗主题切换、多工作区配置
- **开源可改**：用户可自行修改代码，遇到问题可拉取源码直接提问

## 已知缺点

- 修改工作目录内容后无法在工具内直接刷新查看，需到本地文件夹操作
- 右键在访达打开技能目录功能有 bug（截至演示时版本）
