## 定义
FAL 是一个 AI 模型托管平台，托管所有主流 AI 创作模型，支持文生图、图生视频、视频补全、Topaz 放大等所有类型的生成能力。

## 核心能力/特点
- 托管所有主流 AI 创作模型
- 支持文生图、图生视频、视频转视频、Topaz 视频放大
- 提供 API 接口供 AI agent 调用
- Gen Media 技能基于 FAL API 开发，内置 mini app
- 生成内容存在本地数据库
