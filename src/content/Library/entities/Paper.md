## 定义
Paper 是一款专为 AI agent 设计的类 Figma 工具，HTML 架构，内置 MCP 工具，可连接 Codex 使用，支持创建专业交互式示意图。

## 核心能力/特点
- 专为 AI agent 设计的类 Figma 工具
- HTML 架构，内置 MCP 工具
- 支持创建带动画的交互式示意图
- AI 可实时设计，用户截图反馈通过 steering 功能实时修正
- 支持导出 PNG 格式
- 常用场景：创意构思、落地页设计、lead magnet、封面图、品牌规划
