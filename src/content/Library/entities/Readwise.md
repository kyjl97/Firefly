## 定义
Readwise 是一款第二脑知识库工具，可同步 Twitter 书签、网页高亮、Kindle 笔记等到中央数据库，支持 CLI 工具供 AI agent 访问。

## 核心能力/特点
- 同步 Twitter 书签（自动每日同步）
- Chrome 扩展一键保存网页内容并添加备注
- 中央数据库存储所有保存内容
- CLI 工具支持 AI agent 访问所有保存内容
- 可与 Codex/Claude Code 结合生成内容创意
