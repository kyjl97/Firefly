## 定义

GitHub 上一个给 Claude Code 等 AI 编程助手使用的 Skill 框架，拥有 10 万 Star。

## 核心能力/特点

- 提供结构化开发流程：头脑风暴 → 写计划 → 并行开发
- 包含 Brainstorming（头脑风暴）Skill
- 包含 Writing Plans（写实施计划）Skill
- 包含 Dispatching Parallel Agents（并行开发）Skill
- 支持多 Agent 并行协作开发
- 通过共享接口定义实现模块间协作
