## 定义

The Vibe Companion 是一个开源项目，通过逆向 Claude Code CLI 的 WebSocket 协议，将其命令行交互界面搬进浏览器，提供可视化的 Web 操作体验。

## 核心能力/特点

- **多会话并行**：支持同时运行多个 Claude Code 实例，每个实例拥有独立进程和权限设置
- **可视化工具调用流**：Bash 命令、文件读写、代码修改均以折叠块形式清晰呈现
- **零额外成本**：无需额外 API Key，直接复用现有 Claude Code 订阅
- **一键启动**：通过 Bun 环境一行命令即可本地启动
