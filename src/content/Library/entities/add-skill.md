## 定义

Vercel Labs 开发的 CLI 工具，从 GitHub 项目中自动提取并配置 Skill 文件到 Claude Code、Codex、Cursor 等 AI 编程助手。

## 核心能力/特点

- **一行命令安装**：`npx skills add <owner>/<repo>` 自动完成 Skill 配置
- **多平台支持**：Claude Code、Codex、Cursor 等主流 AI 编程助手
- **自动识别**：识别仓库中标准化配置文件完成安装，无需手动复制
- **GitHub**：`github.com/vercel-labs/add-skill`
