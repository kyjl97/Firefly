## 定义

归藏出品的电子杂志风网页 PPT Skill，生成单文件 HTML，浏览器打开横向翻页，上线一周 GitHub 4.5k star。

## 核心能力/特点

- **风格定位**：电子杂志 x 电子墨水路线，视觉冲击力和氛围感强
- **十种页面布局**：封面页、要点页、对比页、时间线页等
- **五套主题色预设**：一键切换
- **适用场景**：线下分享、产品发布、私享会（需要"抬头看屏幕"的场合）
- **与花叔 PPTX 对比**：花叔偏正式 PPTX（U 盘带去客户），归藏偏视觉震撼
- **安装**：`npx skills add op7418/guizang-ppt-skill --skill guizang-ppt-skill`
- **GitHub**：`github.com/op7418/guizang-ppt-skill`
