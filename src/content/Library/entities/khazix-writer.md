## 定义

卡兹克把自己写公众号长文的完整方法论封装成的 Claude Code Skill，通过四层自检体系确保文章质量，像一个"比你更挑剔的编辑"。

## 核心能力/特点

- **四层自检体系**：事实核查→逻辑链排查→AI 腔识别与改写→节奏打磨
- **方法论封装**：不是套模板，是把多年爆款文章积累的判断力变成可执行规则
- **不替代思想**：Skill 不能替代你的观点，但能帮你打磨表达
- **安装**：`npx skills add KKKKhazix/khazix-skills --skill khazix-writer`
- **GitHub**：`github.com/KKKKhazix/khazix-skills`
