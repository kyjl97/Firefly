## 定义

开源 AI 工具合集，涵盖网页爬取、PDF 处理、语音合成三个领域的高质量开源项目。

## 核心能力/特点

### FireCrawl（网页爬取）
- GitHub 3 万 star，零门槛使用
- 擅长动态内容（评论区、瀑布流、图片加密数据流）
- 自动清洗成 Markdown 格式
- 免费开源本地部署 + 在线使用

### OCRmyPDF（PDF 处理）
- GitHub 2 万 star，OCR + Transformer 架构
- 10 秒将扫描件/手写笔记转为可编辑文档
- 支持 100+ 国语言，比 Adobe 快 13 倍
- Windows/Mac/Linux 全平台，8GB 内存即可

### Index TTS2（语音合成）
- B 站开源语音合成大模型，GitHub 1 万 star
- 音质还原度高，情绪起伏自然
- 支持声音克隆，输入文本生成指定音色语音
- 本地部署门槛高，推荐英博云等云端 GPU 平台
