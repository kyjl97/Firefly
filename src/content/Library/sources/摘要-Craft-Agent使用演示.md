## 核心摘要

- **Craft Agent 定位**：免费开源的 AI 工作工具，面向普通非程序员用户，配置简单无需命令行，支持所有主流大模型服务商，可自行修改代码做个性化调整
- **对比 Claude Code**：Claude Code 配置好模型后可自动完成复杂任务，但对非程序员门槛较高；Craft Agent 配置步骤更简单，界面颜值高，支持并行执行多个任务
- **对比其他工具**：阿里 Hotword 操作简单但无法直接查看文件；智谱 Z Code 支持自定义模型但无法并行任务；Code Work 需要购买套餐
- **核心功能**：任务管理（按状态筛选/打标签）、并行任务执行、MCP 与本地文件夹资源支持、技能安装与创建、自动化任务（定时/事件触发）、对话链接分享
- **技能体系**：三级存储优先级（项目级 > 工作区级 > 全局级），支持从技能商店安装，安装 find_skill 后可自动查找安装其他技能
- **执行模式**：EXPLORE（仅可读）、ASK（需确认写操作）、EXECUTE（自动执行）
- **已知缺点**：修改工作目录内容后无法在工具内直接刷新；右键在访达打开技能目录功能有 bug
- **实际演示**：整理混乱下载文件夹——AI 先统计文件类型数量、输出整理方案，用户确认后自动执行并检查结果
