## 核心摘要
- **产品定位**：Flow CLI 是一款命令行 AI 助手，支持文件整理、音视频处理、编程辅助等功能，永久免费
- **核心功能**：文件整理（自动分析文件类型并分类）、音视频处理（提取音频/格式转换/PDF 转 Word）、编程辅助（不会代码也能做网页）
- **安装步骤**：先装 Node.js → 激活命令行 → 输入安装命令 → 配置三步曲（验证方式/APIKey/选 AI 模型）
- **使用技巧**：`at` 选择文件、`Esc` 紧急打断、`Ctrl+C` 退出、`Ctrl+X` 召唤记事本输入长文本、`/` 查看功能速查
- **同类对比**：Flow CLI 永久免费+功能丰富+本土化支持好（缺点：做好的网页不好分享）vs Cloud Code/Gemini CLI 国外知名（缺点：有使用门槛+免费额度少）
- **搭配推荐**：安装 ffmpeg 和 Python 解锁更多高级操作；搭配"搭扣"平台实现项目规划→代码编写→网页部署全自动化
