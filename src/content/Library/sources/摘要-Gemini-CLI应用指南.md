## 核心摘要

- **核心定位**：Gemini CLI 在代码场景不及 Claude Code，但在智能化控制电脑方面有独特优势，普通用户也能通过自然语言指令完成批量处理和自动化工作流。
- **10 大应用场景**：①整理会议纪要（100k 超长上下文）→ ②批量图片识别+重命名 → ③Obsidian 笔记库自动知识图谱生成 → ④本地文档生成 PPT（配合 Slidev）→ ⑤Markdown 与 Word 互转（配合 Pandoc）→ ⑥批量 YouTube 视频下载+摘要（配合 yt-dlp）→ ⑦视频批量剪辑+水印+配乐（配合 ffmpeg）→ ⑧桌面文件夹自动分类整理 → ⑨批量图片加滤镜/拼接海报（配合 ImageMagick）→ ⑩一键设置深度工作环境。
- **核心优势**：技术无门槛（自然语言替代复杂命令行）、跨场景适用（文档/媒体/自动化）、效率提升显著（批量处理减少重复劳动）。
- **工具生态**：Gemini CLI 负责协调第三方工具（Slidev、yt-dlp、ImageMagick、Pandoc、ffmpeg）的执行逻辑。
