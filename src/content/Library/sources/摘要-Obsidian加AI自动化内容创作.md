## 核心摘要

- **核心思路**：卡帕西仅教用户抓取网页建立静态 wiki，真正有价值的是打造懂自己的可进化系统。作者用 Cloud Code 在 Obsidian 中连续创作 200 多张漫画，解决了 AI 生图一致性问题。
- **宝玉 Skills 工具**：GitHub 搜索"宝玉 skill"下载，内置 20 多种视觉风格（信息图、PPT、漫画），支持一键保存和自动配图。
- **五步创作流程**：①锁定人物形象（上传参考图+多轮迭代）→ ②剧情分解（按章回创建含页码、概述、分镜的文件）→ ③文件管理（统一大文件夹+子目录分类）→ ④中央工作流说明书（AI 整理所有要求作为项目大脑）→ ⑤创建专属技能（将自定义要求添加进 Skills，输入指令自动触发全流程）。
- **系统自我进化**：第一回达标率 50%，第二回 70%；创作花费从 30 刀降至 10 刀；废片从 60 多张降至十几张。
- **Git 版本控制**：AI 批量处理文件能力越强，越需要版本控制兜底。安装 Obsidian Git 插件 → `git init` → GitHub 私人仓库 → 自动提交间隔 10 分钟。
- **自动排版配图**：调用宝玉 Skills 自动配图功能，用户选择配图类型、密度、视觉风格，AI 自动格式化文章、规划插图位置、生成图片。
- **发布工具**：Obsidian 中直接预览公众号效果（所见即所得），支持一键发布公众号和推特；飞书 CLI 可在终端直接发送文件获取分享链接。
- **核心价值**：把模糊需求转化为可执行流程，每次对话都在训练 AI 更懂用户。区别于卡帕西的静态 wiki，这是动态可进化的智能系统。
