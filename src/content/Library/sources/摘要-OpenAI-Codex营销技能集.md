## 核心摘要
- **产品定位**：Codex 是 OpenAI 推出的 AI 超级应用，整合聊天、协作、Claude Code 功能到统一体验，95% 的内容和营销任务可在 Codex 内完成
- **技能与插件定义**：插件是技能和能力的集合，技能是给 AI agent 的指令文件；用 / 调用技能，@ 调用插件
- **7+1 核心技能**：
  1. **YouTube Researcher**：接地式内容生成，拉取目标创作者文字稿生成风格匹配内容
  2. **Readwise CLI**：基于第二脑知识库生成内容创意，支持自动化每日生成
  3. **Excalidraw Diagrams**：手绘示意图生成，支持子任务并行加速
  4. **Paper**：AI 专属设计工具（类 Figma），支持实时编辑和导出
  5. **Remotion + Hyperframes**：AI 动效视频生成，精确控制时间线
  6. **Gen Media**：基于 FAL API 的多媒体生成 mini app，支持文生图/图生视频
  7. **Gmail 品牌合作管理器**：自动过滤合作邮件、生成优先级表格、预约会议
  - **Bonus: Buffer Publisher**：社交内容创意存储与导出
- **核心理念**：技能可编辑性降低自定义门槛（自然语言修改）、技能堆叠放大效率、人机协作比纯 AI 自动化更实用（AI 生成初稿，人做最后 10% 修改）
- **获取地址**：chorus.com/skills，兼容 Codeex 和 Claude Code
