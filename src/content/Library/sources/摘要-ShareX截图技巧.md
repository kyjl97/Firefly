## 核心摘要
- **核心功能**：多区域截图加特效，一次性截取多个不相邻区域，自动拼接在一张图片上并添加背景，省去 PS 拼接步骤
- **安装使用**：官网下载安装即用，支持 Windows 10/11；左侧功能导航栏+右侧任务历史记录
- **操作流程**：设置快捷键（如 F1）→ 截图后在任务列表左键单击查看 → 加粗代表当前生效的动作 → 在动作设置的图像特效配置中添加效果
- **多区域模式**：在任务设置里找到区域截图，勾选"使用多区域模式"；或在按下截图快捷键后选择多区域模式
