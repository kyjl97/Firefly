## 核心摘要

- **工具介绍**：markamd 是一个专为 AI 聊天上下文管理场景设计的 Markdown 编辑器
- **技术栈**：基于 Tauri + React + TypeScript 构建，跨平台支持 macOS / Windows / Linux
- **核心功能**：
  - 左侧 CodeMirror 6 编辑器
  - 右侧 markdown-it + Shiki + Mermaid 实时预览
  - 支持 8 套主题、Vim 模式、命令面板
  - 文件侧边栏、阅读模式、PDF 导出
- **开源地址**：https://github.com/mattenarle10/markamd
