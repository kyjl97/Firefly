## 核心摘要

- **核心问题**：剪映自带字幕识别专名不准（"成峰"→"乘风"、"Claude Code"→"克劳德扣的"），老版 Agent 准但门槛高（需 AI 编程基础 + 命令行）
- **解决方案**：基于 GitHub 项目 capcut-mate 直接生成可编辑的剪映草稿（非导出 SRT 文件），接火山引擎 ASR 拿时间戳
- **三档准确率**：有口播稿 99%（识别只拿时间戳，文本用稿子）、有错词字典 95%（上下文纠错）、两样都没约 80%
- **5 步流程**：下载 Skills + 配火山 API Key → 准备口播稿/字典 → 导出字幕（/v） → 预设样式 → 剪映打开
- **产物**：SRT 文件 + 剪映原生草稿（含花字、入场动画），需重启剪映才能看到新草稿
- **门槛变化**：从"需要 AI 编程基础"降到"不用懂技术，一个指令跑完"
