## 核心摘要

- **videocut-skills**：视频剪辑 Skill，识别口误/静音/语气词，Whisper 模型生成字幕 + 词典纠错，FFmpeg 底层剪辑，支持自我更新
- **Humanizer-zh**：消除 AI 生成痕迹的 Skill，基于维基百科 AI 写作特征指南，检测内容/语言语法/风格/交流模式维度，中文汉化版
- **Auto-Redbook-Skills**：小红书发布 Skill，自动生成文案 + Playwright 浏览器自动化渲染为图片 + 模拟操作一键发布，支持 Python/Node.js
- **add-skill**：Vercel Labs 开发的 CLI 工具，从 GitHub 项目提取并配置 Skill 文件，支持 Claude Code/Codex/Cursor，一行命令完成安装
