## 核心摘要

### FireCrawl（AI 爬虫）
- GitHub 3 万 star，零门槛使用，只需注入目标网址即可爬取。特别擅长动态内容（评论区、瀑布流、图片加密数据流）。自动清洗成 Markdown 格式，提供免费开源本地部署和在线使用。

### OCRmyPDF（AI PDF 处理）
- GitHub 2 万 star，融合 OCR 和 Transformer 架构，10 秒将扫描件/手写笔记转为可编辑文档。支持 100+ 国语言，命令行批量处理，8GB 内存老电脑处理速度比 Adobe 快 13 倍。Windows/Mac/Linux 全平台支持。

### Index TTS2（语音合成）
- B 站开源语音合成大模型，GitHub 1 万 star。音质还原度高，情绪起伏自然。支持声音克隆，输入文本即可生成指定音色的语音。本地部署门槛高，可通过英博云等云端 GPU 平台运行（新人送 50 元额度，约 25 小时 4090 显卡）。
