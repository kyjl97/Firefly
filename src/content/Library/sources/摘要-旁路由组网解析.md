## 核心摘要
- **核心价值**：无需改变家庭原有网络结构，主路由保留基础功能，软路由专注科学上网等扩展任务；通过 DHCP 静态绑定+标签规则精准控制设备是否走代理
- **配置步骤**：主路由保持默认 → 软路由刷 OpenWrt 系统（LAN 口连接主路由 LAN 口，禁用 WAN 口）→ 设置旁路由静态 IP → 关闭主路由 DHCP → 通过 MAC 地址静态绑定实现 IP 固定分配 → 添加设备分流规则
- **典型问题**：(1) 非对称路由导致国内网站访问失败 — 关闭"丢弃无效数据包"或开启 IP 动态伪装；(2) WiFi 设备无法访问国内网站 — 开启 LAN 区域 IP 动态伪装；(3) IPv6 绕过旁路由 — 关闭主路由与旁路由的 IPv6 功能
- **争议与本质**：旁路由因非标准拓扑被部分用户排斥，但本质与"透明网关""网关代理"一致；家庭简单网络可稳定使用，复杂网络易冲突
