## 核心摘要
- **核心原理**：软件的代码与界面资源分离，所有可见元素（图标、菜单、对话框）均可通过工具修改
- **工具准备**：Resource Hacker（资源编辑工具，官网下载避免第三方站）+ 目标软件英文原版 + AI 翻译工具（如 DeepSeek 批量翻译）
- **操作流程**：备份主程序 → Resource Hacker 加载 .exe → 展开资源树 → 定位 1033 代码段（英文资源）→ 菜单/对话框/右键菜单逐项翻译 → 编译保存 → 替换原文件
- **批量翻译技巧**：全选菜单文本（Ctrl+A）→ 复制至 AI 工具输入"汉化这段文本" → 粘贴翻译结果回 Resource Hacker
- **适用范围**：适用于大多数 Windows 桌面软件（已验证 EditPlus/Space Sniffer/WinRAR）；不涉及软件破解，仅修改界面资源
- **注意事项**：部分软件可能采用加密资源导致汉化失败；修改系统文件前务必备份
