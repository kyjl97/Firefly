## 核心摘要

- **产品定义**：飞书 MCP 是飞书文档集成 AI 能力的扩展功能，通过配置企业自建应用实现文档自动化处理、数据抓取与消息推送。
- **配置流程**：访问飞书开发者后台 → 创建企业自建应用 → 添加机器人能力 → 配置权限（云文档/消息/多维表格/用户身份）→ 创建版本提交审批 → 获取 App ID 和 App Secret → 本地安装 Node.js → 执行 `openapi mcp` 登录 → `cloud mcp add` 添加配置。
- **核心功能**：文档自动化（命令创建飞书文档）、数据抓取与表格生成（自动抓取笔记数据整理至多维表格）、消息自动推送（向指定群组发送预设消息）。
- **权限控制**：需 8 项准备工作和多步骤权限配置，较同类产品复杂但提供更精细的权限控制。需管理员审批流程，适合企业环境。
- **常见问题**：登录失败需配置重定向 URL；消息发送权限不足时可通过错误提示链接直达配置页面。
