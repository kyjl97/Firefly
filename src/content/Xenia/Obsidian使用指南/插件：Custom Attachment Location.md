```Plain
Custom Attachment Location
```

### 插件设置
1. 附件重命名模式→全部
2. 是否重命名附件文件→开启
3. Markdown URL格式填写
```Plain
assets/${noteFileName}/${generatedAttachmentFileName}
```

**文件与链接**
- 内部链接类型→基于当前笔记的相对路径
- 使用wiki链接→取消（特别容易忽略)

### 补充：删除笔记中引用无效的图片url
该插件会从所有Markdown*文档中提取*您的所有*图片链接*，并将这些图片与您在Vault中*可用的所有图像文件进行比对*。
如果这些图像文件在档案库的任何文档中均未被引用，它们将被自动删除。
```
Clear Unused Images
```
