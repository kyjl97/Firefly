## ⚡ 高频必记（按使用频率排序）
| 快捷键       | 是否需要 Shift | 功能说明           |     |
| :-------- | :--------- | :------------- | --- |
| `j` / `k` | ❌ 不需要      | 向下 / 向上滚动（最核心） | 常用  |
| `gg`      | 双击         | 跳转到页面顶部        | 常用  |
| `G`       | ✅ 需要 Shift | 跳转到页面底部        | 常用  |
| `d` / `u` | ❌ 不需要      | 向下 / 向上滚动半页    | 常用  |
| `r`       | ❌ 不需要      | 刷新当前页面         |     |
| `/`       | ❌ 不需要      | 开启页面查找模式       |     |
| `n`       | ❌ 不需要      | 查找下一个匹配项       |     |
| `N`       | ✅ 需要 Shift | 查找上一个匹配项       |     |
| `t`       | ❌ 不需要      | 新建标签页          | 常用  |
| `x`       | ❌ 不需要      | 关闭当前标签页        | 常用  |
| `X`       | ✅ 需要 Shift | 恢复刚关闭的标签页      |     |
| `J` / `K` | ✅ 需要 Shift | 切换到左边 / 右边的标签页 | 常用  |
| `H` / `L` | ✅ 需要 Shift | 浏览器历史后退 / 前进   |     |
| `yy`      | ❌ 不需要      | 复制当前页面URL到剪贴板  | 常用  |
| `gi`      | ❌ 不需要      | 快速聚焦页面第一个输入框   | 常用  |
| `?`       | ✅ 需要 Shift | 打开Vimium帮助面板   |     |

## 📋 全快捷键清单（带 Shift 标注）
### 1. 页面导航（滚动与跳转）
| 快捷键 | 是否需要 Shift | 功能说明 |
| :--- | :--- | :--- |
| `j` / `<c-e>` | ❌ 不需要 | 向下滚动 |
| `k` / `<c-y>` | ❌ 不需要 | 向上滚动 |
| `gg` | ❌ 不需要 | 滚动到页面顶部 |
| `G` | ✅ 需要 Shift | 滚动到页面底部 |
| `d` | ❌ 不需要 | 向下滚动半页 |
| `u` | ❌ 不需要 | 向上滚动半页 |
| `h` | ❌ 不需要 | 向左滚动 |
| `zl` / `zL` | ❌/✅ 小写/大写 | 滚动到页面最右侧 |
| `r` | ❌ 不需要 | 刷新页面 |
| `gi` | ❌ 不需要 | 聚焦到页面的第一个文本输入框 |
| `gf` | ❌ 不需要 | 选择页面上的下一个框架 |
| `gF` | ✅ 需要 Shift | 选择页面的主/顶部框架 |

### 2. 标签页操作
| 快捷键 | 是否需要 Shift | 功能说明 |
| :--- | :--- | :--- |
| `t` | ❌ 不需要 | 新建标签页 |
| `J` / `gT` | ✅ 需要 Shift | 切换到左侧标签页 |
| `K` / `gt` | ✅/❌ 大写/小写 | 切换到右侧标签页 |
| `^` | ✅ 需要 Shift | 切换到上一个访问过的标签页 |
| `g0` | ❌ 不需要 | 跳转到第一个标签页 |
| `g$` | ✅ 需要 Shift | 跳转到最后一个标签页 |
| `yt` | ❌ 不需要 | 复制当前标签页并新建副本 |
| `<a-p>` | ❌ 不需要 | 固定/取消固定当前标签页 |
| `<a-m>` | ❌ 不需要 | 静音/取消静音当前标签页 |
| `x` | ❌ 不需要 | 关闭当前标签页 |
| `X` | ✅ 需要 Shift | 恢复已关闭的标签页 |

### 3. URL 与 Vomnibar（地址栏/搜索栏）
| 快捷键 | 是否需要 Shift | 功能说明 |
| :--- | :--- | :--- |
| `yy` | ❌ 不需要 | 复制当前页面URL到剪贴板 |
| `p` | ❌ 不需要 | 在当前标签页打开剪贴板中的URL |
| `P` | ✅ 需要 Shift | 在新标签页打开剪贴板中的URL |
| `F` | ✅ 需要 Shift | 在新标签页打开链接（带提示） |
| `o` | ❌ 不需要 | 打开URL、书签或历史记录（当前标签页） |
| `O` | ✅ 需要 Shift | 在新标签页打开URL、书签或历史记录 |
| `b` | ❌ 不需要 | 打开书签（当前标签页） |
| `B` | ✅ 需要 Shift | 在新标签页打开书签 |
| `T` | ✅ 需要 Shift | 搜索所有已打开的标签页 |
| `ge` | ❌ 不需要 | 编辑当前URL并跳转 |
| `gE` | ✅ 需要 Shift | 编辑当前URL并在新标签页打开 |

### 4. 查找与历史记录
| 快捷键 | 是否需要 Shift | 功能说明 |
| :--- | :--- | :--- |
| `/` | ❌ 不需要 | 开启页面查找模式 |
| `n` | ❌ 不需要 | 跳转到下一个查找结果 |
| `N` | ✅ 需要 Shift | 跳转到上一个查找结果 |
| `H` | ✅ 需要 Shift | 浏览器历史后退 |
| `L` | ✅ 需要 Shift | 浏览器历史前进 |

### 5. 其他模式与杂项
| 快捷键 | 是否需要 Shift | 功能说明 |
| :--- | :--- | :--- |
| `i` | ❌ 不需要 | 进入插入模式（暂时禁用Vimium快捷键） |
| `v` | ❌ 不需要 | 进入可视模式（文本选择） |
| `?` | ❌ 不需要 | 打开Vimium帮助面板 |
