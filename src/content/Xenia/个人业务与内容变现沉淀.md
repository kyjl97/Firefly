## 一、当前阶段

### 已知数据

| 项目 | 当前情况 |
|---|---|
| 月收入 | 约3000元 |
| 目标收入 | 每月稳定5000～10000元以上 |
| 当前平均客单价 | 约50元 |
| 当前主要订单 | 软件安装、远程排错 |
| 当前订单特点 | 软件安装出单最多，基本没有售后 |
| 已验证数字产品 | Codex App 指南，已经卖出几单 |
| 未验证产品 | Obsidian 模板，目前没有出单 |
| 高风险产品 | GPT Plus 成品号与代充，封号和补号售后不可控 |

如果月收入3000元全部按50元客单价估算，相当于每月约60单。这个数字只能作为粗略换算，后续需要记录不同产品的真实订单结构。

### 当前优势

- 能在 Windows 环境里真正安装、配置和排错
- 能处理普通用户最容易卡住的环境、API、网络和软件问题
- 熟悉 Codex、Claude Code、Obsidian、AI Agent、Skill 和个人网站
- 有博客、教程、脚本、网站和实际操作记录作为信任基础
- 用户不想自己折腾时，可以直接提供远程交付

### 当前瓶颈

- 会做的事情很多，核心招牌服务还不够集中
- 50元服务如果没有明确边界，容易被复杂问题拖长时间
- 内容很多，但过去缺少“文章 → 咨询 → 成交 → 案例”的持续追踪
- 高价值工作流和 Skill 定制还没有形成稳定成交
- 部分产品有需求，但售后和平台风险不受自己控制

## 二、已经验证的业务判断

### 1. 软件安装可以继续做

软件安装已经有真实订单，交付完成后基本没有售后，适合作为稳定现金流入口。

50元价格可以保留，但只对应边界明确的基础安装：

- 单个常见软件
- 正常 Windows 环境
- 预计30分钟内完成
- 软件成功启动
- 完成一次基础运行验证
- 不包含复杂报错、多软件联动、账号和后续新增问题

### 2. Codex App 指南值得继续迭代

指南已经卖出几单，说明用户愿意为清楚、可执行的资料付费。它适合作为低门槛产品，也可以筛选需要远程安装和进一步配置的人。

后续可以继续补充：

- Windows 安装方法
- 常见安装失败处理
- 登录与基础设置
- 工作目录和权限问题
- 常见报错检查清单
- 什么时候适合购买远程服务

### 3. Obsidian 模板不再单独作为主产品

模板目前没有出单，暂时不能证明用户愿意单独为一批模板文件付费。

后续调整为：

- 免费体验或低价入口
- Obsidian 写作工作流中的组成部分
- 定制知识库的交付组件
- Codex + Obsidian 个人 AI 工作台的一部分

内容重点从“模板有什么”改为“它解决了哪个具体问题”。

### 4. GPT Plus 成品号不作为长期主营

成品号有需求，但账号可能几天内被封。售价还要承担补号、远程操作、客户沟通和信誉风险，成本无法稳定预测。

当前决策：

- 停止把成品号作为核心产品
- 不承诺第三方账号永久稳定
- 已有订单按照原约定处理，或者经客户同意折算为其他服务
- 后续只提供客户本人持有账号的合规开通指导、安装和配置服务

## 三、服务分级方案

> [!warning] 价格说明
> 除50元基础安装外，下面的价格均为待测试方案。先用5～10个新订单验证成交率、交付时间和售后，再决定是否长期使用。

### 一级：基础安装

**参考价格：50元**

- 安装一个常见软件
- 不涉及复杂环境和多软件联动
- 完成启动与基础运行验证
- 同一个问题在约定时间内可以复查一次

### 二级：安装、配置与排错

**测试价格：99～199元**

- 安装软件
- 配置运行环境
- 处理一个明确报错
- API 或模型基础配置
- 完成一次真实运行验证

### 三级：Codex或Claude Code标准配置

**测试价格：199～399元**

- Codex或Claude Code安装
- 模型、API和基础环境配置
- 工作目录和常用规则设置
- 完成一个真实任务
- 一次基础使用指导

### 四级：个人AI工作台

**测试价格：499～999元**

- Codex或Claude Code
- Obsidian知识库
- 常用Skills
- 一个内容生产或资料整理流程
- 一次远程培训
- 约定范围内的后续调整

### 五级：定制与长期服务

**按需求评估，复杂项目不再按50元统一报价**

- AI Agent Skill定制
- 自动化流程
- 多工具连接
- 个人网站和笔记网站
- 长期技术顾问

## 四、50元客单价达到8000元的推算

如果平均客单价始终保持50元：

```text
8000 ÷ 50 = 160单/月
```

| 工作节奏 | 平均订单量 |
|---|---:|
| 每月30天接单 | 每天约5.3单 |
| 每月26天接单 | 每天约6.2单 |
| 每月22天接单 | 每天约7.3单 |
| 每月20天接单 | 每天8单 |

### 时间成本

| 单笔总耗时 | 160单需要时间 | 按22天计算 |
|---|---:|---:|
| 15分钟 | 40小时/月 | 1.8小时/天 |
| 30分钟 | 80小时/月 | 3.6小时/天 |
| 45分钟 | 120小时/月 | 5.5小时/天 |
| 60分钟 | 160小时/月 | 7.3小时/天 |

如果每单还有10分钟沟通时间，160单会额外增加约27小时。

### 咨询量要求

| 咨询成交率 | 每月所需有效咨询 | 平均每天 |
|---|---:|---:|
| 30% | 约534人 | 约18人 |
| 40% | 400人 | 约13人 |
| 50% | 320人 | 约11人 |
| 60% | 约267人 | 约9人 |

### 判断

平均50元做到8000元并非不可能，但必须同时满足：

- 每天稳定获得9～18个有效咨询
- 每天处理6～8个付费订单
- 单笔总耗时尽量控制在30～40分钟
- 安装流程高度标准化
- 售后边界清楚
- 下载、安装和验证步骤尽量自动化

如果大部分订单需要一小时以上，50元客单价很难长期稳定达到8000元。

## 六、内容与成交路径

### 内容方向

- 40%：AI工具安装、Windows环境和报错修复
- 30%：Codex、Claude Code与AI Agent实际使用
- 20%：Obsidian知识管理、写作与AI工作流
- 10%：个人网站、内容发布以及与服务相关的工具变化

### 内容形式

- 60%具体问题
- 30%真实案例
- 10%工具变化与观点

### 转化路径

```text
安装失败、报错和使用问题
→ 搜索文章、短视频和检查清单
→ Codex指南或基础安装
→ 配置、排错和使用指导
→ 个人AI工作台
→ Skill、自动化和网站定制
```

### 一单一资产

每完成一项服务，至少沉淀一种资产：

- 一篇教程
- 一条真实案例
- 一份检查清单
- 一套SOP
- 一个脚本
- 一个可复用Skill
- 一条新的报价边界

同一个问题处理三次，就评估是否可以做成标准服务、教程或工具。

## 八、订单数据记录

以后每笔订单至少记录：

| 字段 | 说明 |
|---|---|
| 日期 | 收款或开始服务日期 |
| 客户来源 | 公众号、博客、短视频、朋友介绍等 |
| 对应文章 | 哪篇内容带来的咨询 |
| 服务类型 | 安装、排错、指南、工作流、Skill、网站等 |
| 收入 | 实际收款金额 |
| 操作时间 | 真正远程操作用了多久 |
| 沟通时间 | 售前、等待和售后沟通时间 |
| 是否售后 | 是否出现复查、补做或退款 |
| 最终结果 | 完成、部分完成、未完成 |
| 可沉淀资产 | 教程、案例、SOP、脚本或Skill |

每月底重点计算：

```text
真实时薪 = 月实际收入 ÷ 服务与沟通总时间
成交率 = 成交订单数 ÷ 有效咨询数
售后率 = 发生售后的订单数 ÷ 总订单数
内容转化率 = 内容带来的成交数 ÷ 内容带来的有效咨询数
```

## 十、阶段判断

目前已经跨过“有没有人愿意付钱”的阶段。接下来要验证的是：能否把零散技术服务变成边界清楚的标准产品，并让一部分低价安装客户自然升级到配置、工作流和定制服务。

短期先以连续三个月稳定5000元为目标。达到以后，再根据订单结构、真实时薪和高价值服务占比判断怎样冲击1万元。
