 根据搜索结果，您的错误代码 **-2143309801** 是 Windows 应用商店应用（MSIX 格式）启动时的文件系统错误。这通常不是 Codex 本身的问题，而是 Windows 系统组件异常导致的。

## 错误原因分析

您的 Codex 是通过 **Microsoft Store（微软商店）** 安装的 MSIX 格式应用。这类应用依赖 Windows 的以下系统组件：
- **App Installer**（应用安装器）
- **Windows 应用部署服务**
- **微软商店相关功能**

当这些组件损坏或异常时，就会出现"文件系统错误"。

---

## 推荐解决方法（按优先级排序）

### 方法一：修复 Windows 应用商店和 MSIX 组件

以**管理员身份**打开 PowerShell，依次执行以下命令：

```powershell
# 1. 重置 Windows 应用商店缓存
wsreset.exe

# 2. 重新注册所有 UWP 应用（修复应用部署）
Get-AppxPackage -AllUsers | Foreach {Add-AppxPackage -DisableDevelopmentMode -Register "$($_.InstallLocation)\AppXManifest.xml"}

# 3. 修复 Microsoft Store 本身
Get-AppxPackage *WindowsStore* | Reset-AppxPackage
```

执行后**重启电脑**，再尝试启动 Codex。

---

### 方法二：检查关键系统服务

按 `Win + R`，输入 `services.msc`，检查以下服务是否正常运行：

| 服务名                                   | 状态          |
| ------------------------------------- | ----------- |
| **Windows License Manager Service**   | 设为"自动"并启动   |
| **AppX Deployment Service (AppXSVC)** | 设为"自动"并启动   |
| **Microsoft Store Install Service**   | 设为"手动"或"自动" |



---

### 方法三：重新安装 Codex

如果上述方法无效，可以尝试通过 PowerShell 手动重新安装：

```powershell
# 先卸载现有的 Codex
Get-AppxPackage *OpenAI.Codex* | Remove-AppxPackage

# 然后从微软商店重新安装
# 或者下载 .msix 安装包后用以下命令安装：
Add-AppxPackage -Path "C:\路径\到\OpenAI.Codex.msix"
```

---

### 方法四：运行系统文件检查

以管理员身份打开 CMD 或 PowerShell，执行：

```powershell
# 扫描并修复系统文件
sfc /scannow

# 修复 Windows 映像
DISM /Online /Cleanup-Image /RestoreHealth
```
