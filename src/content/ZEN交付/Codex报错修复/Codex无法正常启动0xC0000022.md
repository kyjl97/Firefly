## 错误现象

Codex 打开后弹窗：**"应用程序无法正常启动(0xC0000022)。请单击'确定'关闭应用程序。"**
![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260610231257902.webp)

## 原因

沙盒模式（elevated）下，沙盒用户没有权限读取系统 VC++ 运行库 DLL。

---

## 方案一：改 sandbox 为 unelevated（推荐先试）

编辑 `%USERPROFILE%\.codex\config.toml`：

```toml
[windows]
sandbox = "unelevated"
```

然后完全重启 VS Code / Codex App。

---

## 方案二：修复 VC++ 运行库 DLL 权限

检查 `C:\Windows\System32` 下的这两个文件：

- `vcruntime140.dll`
- `msvcp140.dll`

每个文件：右键 → 属性 → 安全 → 编辑

确保 **Users** 组存在，且勾选了 **"读取和执行"** 权限。如果缺少 Users 组，点"添加"→ 输入 `Users` → 确定。

---

## 方案三：关闭沙盒

编辑 `%USERPROFILE%\.codex\config.toml`，添加：

```toml
sandbox_mode = "danger-full-access"
```

或在终端运行：

```
codex --sandbox danger-full-access
```
