### 今日创建笔记
```dataview
TABLE WITHOUT ID
  category AS "分类",
  dateformat(file.ctime, "yyyy/MM/dd") AS "创建日期",
  file.link AS "今日创建"
WHERE file.cday = date(today)
SORT category ASC, file.ctime DESC
```




### 今日更新笔记
```dataview
TABLE WITHOUT ID
  category AS "分类",
  dateformat(file.mtime, "yyyy/MM/dd") AS "更新日期",
  file.link AS "今日更新"
WHERE file.mday = date(today) 
  AND file.cday != date(today)
SORT category ASC, file.mtime DESC
```
