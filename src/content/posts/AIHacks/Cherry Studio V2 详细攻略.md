> 以下以视频作者（技术爬爬虾）的第一人称视角整理，文中的「我」均指视频作者；案例提示词已逐条提取为代码块，可直接复制去 Cherry Studio 里测试。

Cherry Studio 是我第一天学习 AI 就焊死在电脑里的软件。

它是一个开源免费的全能 AI 工作站，在 GitHub 上已经有 48K star，集成了对话、Agent、知识库、画图、翻译等功能。最近，Cherry Studio 全面重构后的 V2.0 版本上线了。这期内容就来做一个详细攻略，重点介绍 V2 的主要更新，并分享几个我在工作中天天都在用的真实场景。

## 一、为什么我把 Cherry Studio 当模型测试工具

Cherry Studio 提供了极其丰富且方便的 AI 模型接入功能，覆盖了国内外大部分主流模型以及本地推理框架。

> 如果有人给我一个 HTTP 接口让我测试，我第一反应是打开 Postman；但如果别人给我一个模型让我测试，那我第一反应肯定是打开 Cherry Studio。

### 1. 快速接入官方模型

在左下角点击「设置」，找到「模型服务」，这里面有 60 多家模型提供商。比如最近 Kimi K3 发布了，我想测试一下新模型的实例，就在模型供应商里找到「月之暗面」，填写 API 密钥。Cherry Studio 的「获取密钥」小按钮可以直接跳转到对应模型的 API 开放平台，创建 key 后粘贴回来，然后点击「获取模型列表」，它会自动拉取最新模型，选择 KIMIK3 就完成了配置。

接下来回到对话，选择刚才添加的模型，跟 AI 聊天，如果能正常返回，说明 API 配置成功。

### 2. 用 Token 数据对比模型速度与利用率

在设置的外观里打开「预估 token 数」，对话里就会显示花费的 token 数量。鼠标移上去还会显示「首字时延」和「每秒输出量」。

> 我经常用这个数据对比测试模型的 token 利用率，还有输出速度。

### 3. 添加自定义模型服务商

除了列表里已有的提供商，添加其他模型也很方便。比如之前介绍过的 Agnes 模型列表，最下面有「添加服务商」按钮。点击后，把 Agnes API 文档里的 base URL 复制到 Cherry Studio 的 base URL 里，再在文档右上角创建 API 密钥，填写进来，最后在模型处添加对应的模型 ID（如 `Agnes 2.0 Flash`），就搞定了。

## 二、V2 最大升级：Agent 自主执行能力

> Cherry Studio V2 的最大升级是 Agent 能力。它从一个聊天客户端，升级为了 Agent 自主执行的一站式 AI 工作台。现在 AI 能够自主规划任务、调用工具、读写文件、联网搜索，最终直接交付成果。

> Cherry Studio V2 的 Agent 相比我用过的其他 Agent 工具，最大的特色就是超高的自由度：可以自由选择模型、自由配置 Skill 和 MCP、自由选择联网搜索引擎，甚至连 Agent 的工具列表都能自由开启与关闭，非常好玩。

### 1. 配置联网搜索服务

我们先给 Agent 配置一个联网搜索服务。点击左下角的设置，在网络搜索里选择一个搜索服务商。这里我选择 Exa。

> Exa 是一个对开发者真的十分友好的网络搜索引擎，可以用自然语言输入问题来搜索全网内容，而且它提供每月 2 万次的免费调用，足够我们个人用户使用了。

点击「获取密钥」，来到 Exa 官网生成 API key，填写到 Cherry Studio 里，然后点亮右上角的「默认搜索」开关，就完成了配置。

### 2. 安装 Playwright CLI 技能

有了搜索，我们再来添加一个技能。在 Cherry Studio 左侧边栏找到「工作」，也就是智能体面板，展开后找到「管理技能」。它支持本地导入或者在线搜索，这里我选择在线搜索，然后搜索 `Playwright cli`。这是一个让 AI 控制浏览器进行自动化操作的 Skill。我之前有一期完整视频专门介绍用 Playwright CLI 做浏览器自动化，想深入了解的朋友可以参考那一期。

### 3. 创建一个 Agent

然后我们就可以自定义智能体了。点击「添加智能体」按钮，填写名字，选择模型，设定人格提示词，再选择技能，记得勾选刚才安装的 Playwright CLI 技能。

### 4. 实战案例：自动下载物理教材 PDF

前几天我有一位当物理老师的朋友问我，AI Agent 对于他这样的普通人到底有什么用？我们就从他的真实办公场景出发，做几个实战案例。

进入对话后，直接把下面这句话作为提示词发给刚创建的 Agent：

```
下载人教版物理必修第二册的电子教材
```

Cherry Studio 先调用联网搜索，找到了多个候选网站，然后使用 Playwright CLI 自动操作浏览器，在每个候选网站里寻找可下载的链接，完成了下载。点击这个 PDF 文件，就打开了 Cherry Studio V2 新上线的「交付物预览」功能。图片、PDF、Word 等都能在应用内直接查看。

### 5. 多标签页并行工作

Cherry Studio V2 的 UI 体验很像浏览器的多标签页，可以直接点击加号打开多个标签页并行工作，还可以把一个标签页拖拽出来形成独立窗口，多个任务并排执行，一目了然，效率很高，用起来很舒服。

## 三、教育场景：备课与互动教学网页

当老师最枯燥耗时的工作就是写教学材料，我们再来试试这个案例。

### 1. 仿照范文写教学材料

进入对话后，发下面这段提示词，同时把一篇之前写过的教学材料范文直接粘贴在后面作为范例：

```
我需要备课，你仿照我们学校教学材料的格式帮我写一个教学材料
```

（把往期的教学材料范文整段粘贴到这段提示词后面，Agent 会调用工具读取范文内容，仿照格式编写新的教学材料，最后交付 Word 跟 PDF 双格式。在右侧工作区的文件数里，实时展示了 Agent 的产出，交付的文件一目了然。）

### 2. 做 3D 互动教学网页

接下来再上点难度，做一个互动教学网页。把下面这段提示词发给 Agent：

```
把火车转弯的这个例题做成一个3D互动教学的HTML网页。
我需要能够调节速度、轨道倾角、转弯半径、火车质量四个指标，
需要展示受力分析和核心公式。
```

> 在以前版本的 Cherry Studio 里，Agent 只能接 Anthropic 端点，现在 V2 版本里这个限制移除了，可以选择任意模型，哪个效果好就选哪个。这里我用的是新上线的 KIMIK3 Agent，最终完成了任务。可以调节参数速度、轨道倾角等等，受力分析的箭头跟右侧的计算数据都会跟着实时改变，很有意思。

## 四、自媒体写作：纯聊天 + 多模型协同 + 对话分支

我作为一个自媒体博主，经常有很多文字处理的需求，比如写好了一个视频脚本就让 AI 帮着润色一下，或者起个标题啥的。我通常会综合比较十多个模型的输出，选择一个最好的。

> 像 OpenCode、Workbench 这类的桌面 Agent 虽然可以把多个模型集中起来统一管理，但它们本质上是编程工具，都内置了几万 token 的系统提示词，这些提示词会严重干扰 AI 在纯文字工作上的表现。

> 在这个场景下，最适合我的工具就是 Cherry Studio。它的对话功能是一个纯聊天工具，不内置任何编程方面的提示词，而且可以很方便地把海量模型集中管理，还能一次性选择多个模型协同回答。

### 1. 配置「起标题助手」

在 Cherry Studio 左侧边栏找到「对话」，点击「添加助手」→「新建助手」，填写名字（比如「起标题助手」），然后设定人格，也就是输入系统提示词。下面这段就是视频里用的系统提示词，可以直接复制：

```
你是一个给视频脚本起标题的助手。
用户上传视频脚本，你负责生成 10~20 个视频标题给用户挑选。
```

创建助手后，在顶部展开模型选择窗口，启动「多模型同时回答」，可以一次性勾选上十几个模型，然后在底部聊天框丢进来一个视频脚本，回车开始。Cherry Studio 会同时调用十几个模型为我们输出标题，整个过程一目了然，只需要在结果里挑选一个最好的即可。

### 2. 对话分支管理

Cherry Studio 还有一个非常好用的功能——对话分支。比如我通过多轮聊天敲定了大概内容，然后让 AI 帮我写一个脚本，脚本写好后我不太满意，想尝试不同的模型或者风格，这时候就可以在上一次对话末尾点击「分支」，把之前的对话历史完全保留，放到一个新的分支里。我们可以在新分支上尝试不同的模型或写作风格。

点击右上角的分支管理按钮，就展示了整个对话树分支情况的全景图，可以很方便地对比几个版本的差异，做任意版本的回退跟修改。

> Cherry Studio 把写作这件事用工程化的思维管理起来，这才是用 AI 写作的新范式。

## 五、知识库：全文检索与语义检索

> 知识库是我每天都会用的功能。对于普通人来说，Cherry Studio 就是手头上最容易搭建本地知识库的工具了。

### 1. RAG 架构与全文检索

Cherry Studio 的知识库是经典的 RAG 架构，提供两种检索方案：全文检索和向量数据库语义匹配。

先看简单的全文检索。当我们把资料添加进知识库时，Cherry Studio 会把它拆分成许多个文本块，存入本地数据库并建立全文索引。用户搜索时，通过关键词在知识库里进行精确匹配。检索到的原文片段加上用户的问题一起发送给大模型，由大模型做最后的归纳总结。

比如添加好资料后，在召回测试里输入下面这句话，就能检索到原文：

```
体会物理规律
```

但全文检索有个弊端：只能匹配字符串本身，而不是语义。如果换成下面这句话，它就检索不到了：

```
体验练物理规律
```

### 2. 向量数据库语义匹配

这时候可以换用向量数据库进行语义匹配。使用向量数据库的模式下，Cherry Studio 会先调用嵌入模型对文本块进行向量化，把切分后的文本变成一个固定长度的数字序列（也就是向量），然后把向量以及对应的文本存入向量数据库。

当用户提问时，Cherry Studio 会先把问题本身也经过向量化处理，然后与向量数据库进行语义层面的相似度匹配。这个匹配是基于向量的纯数学运算，最后知识库选出匹配度最高的几个原文片段，由大模型进行最后的总结归纳。

### 3. 配置嵌入模型与重排序模型

第一步是配置嵌入模型。来到设置里的模型服务，选择「硅基流动」，它提供免费的嵌入模型调用。点击「获取 API key」，在硅基流动左侧找到 API 密钥，新建后复制出来，填写到 Cherry Studio 里，然后点击获取模型列表，筛选嵌入模型，找到免费的 BGE-M3，把它添加进来。

然后回到知识库右上角的设置，把嵌入模型切换成 BGE-M3，这样 Cherry Studio 会使用嵌入模型重新处理数据，知识库就进化成了向量数据库，具备了语义匹配功能。现在再测试召回，不论是「体验物理规律」还是「体会物理规律」，都能检索到对应段落。

如果想进一步提高检索效果，可以把向量数据库检索出来的结果使用专门的重排序模型进行更深入的语义分析，按照问题相关性重新排序，把相关性最高的文本块排到最前面。硅基流动同样提供免费的重排序模型，同样在模型配置里获取模型列表，筛选重排序，找到 BGE-Reranker-v2-m3 添加进来，然后回到知识库设置里选择它即可。

### 4. 添加目录数据源与实战查询

配置完毕后，我们可以在知识库右上角点击「添加数据源」，选择目录，比如把过去几年的视频脚本目录加进去。

然后回到 AI 的聊天界面，点击加号选择知识库，再询问下面这个问题（视频里原话是「super base」，即 Supabase）：

```
Supabase 里面怎么存地理位置信息
```

Cherry Studio 会先调用知识库工具，检索到文章以及对应的文本块，接下来进行归纳整理，最后输出我需要的知识内容，并且附上原文出处。

> 除了在聊天里使用知识库，现在知识库也可以被 Agent 自主调用。只需要在智能体的设置里确保「知识库搜索」功能开启，Agent 如果需要补充知识时就会自动从知识库里检索，非常方便。

## 小结

> Cherry Studio V2 给我的最大感受是：它把「聊天」「Agent」「知识库」这三件事整合到了一个足够干净、足够自由的桌面上。无论你是想快速测试一个新模型、让 Agent 自动完成一套联网搜索加文件下载的任务，还是想把几年的资料整理成可检索的知识库，它都能在一个应用里完成，而不会被强制塞入一大堆编程相关的系统提示词。

如果你也正在找一个可以长期放在电脑里的 AI 工作站，Cherry Studio V2 值得你认真试试。
