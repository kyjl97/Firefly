你有没有这种感觉。

让 AI 帮你干了一件挺漂亮的事，整理了个文件夹，写了个方案，搞了个数据分析。干完之后你挺满意，关掉对话窗口，过了两天想翻出来看看。

找不到了。

对话记录淹没在一堆历史会话里，你往上翻了十分钟，眼都花了，还是没找到那次到底聊了啥。

说实话，这个问题困扰我挺久的。Claude Code 好用是好用，但它的对话就是一条时间线，没有状态，没有分类，更别说什么归档了。用久了之后，你的历史对话就像一个巨大的垃圾桶，什么都往里扔，什么都找不到。

直到我最近试了一下 Craft Agent。
![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260529172953083.webp)


### 任务面板这个东西，用过就回不去了

Craft Agent 的界面是三栏布局，左边是功能栏，中间是任务列表，右边是对话框。

听起来好像没什么特别的对吧。

但你仔细想想，中间那个任务列表，才是这个工具真正牛逼的地方。

每个任务是一张独立的卡片。你可以给它打标签，可以标记状态，可以筛选。进行中的，已完成的，已取消的，一眼就能分清楚。

我跟你说，就这一个功能，直接治好了我的 AI 焦虑。

以前用 Claude Code 的时候，我的对话窗口里堆了几十个会话，什么「帮我改一下这个文件」「分析一下这个数据」「写个周报」，全混在一起。想找两周前让 AI 整理的那个方案？祝你好运。

现在呢，打开 Craft Agent，切到「已完成」筛选，两秒钟就找到了。

就这么简单。

### 标签，跨项目管理的救星

说到打标签这块，我觉得这个设计是真的用心了。

你可以给每个任务打自定义标签。比如我现在的工作区里，「内容」是一类，「代码」是一类，「杂活」又是一类。

以前不管是用 Cursor 还是 Claude Code，所有对话都是一锅粥。今天写公众号排版是用 AI，明天改代码 bug 也是用 AI，后天让它帮我整理文件还是用 AI。三条线全搅在一起。

有了标签之后，点一下「内容」，所有跟写文章相关的任务都出来了。点一下「代码」，所有跟开发相关的也出来了。

这个东西，用之前觉得没什么，用之后你会觉得，以前自己是怎么忍过来的。

### 执行模式，让你对 AI 的掌控感拉满

Craft Agent 有三种执行模式，EXPLORE、ASK 和 EXECUTE。

EXPLORE 是只读模式，AI 只能看不能动你的文件。ASK 是每次要写文件的时候弹出来让你确认。EXECUTE 是全自动，AI 自己干。

关键是，每个任务可以单独设置执行模式。

这点很重要。你让 AI 整理下载文件夹，这种操作你可以放心开 EXECUTE 让它自己搞。但如果你让 AI 改一个重要的配置文件，你可以切到 ASK，每次写之前都过一眼。

这种掌控感，说实话，在同类工具里是很少见的。

Claude Code 默认就是全权委托，你把任务丢出去就只能等结果。Hotword 和 Z Code 更简单粗暴，连任务状态都看不到。

### 我自己也还在摸索

坦率的讲，Craft Agent 不是完美的。改了工作目录里的文件之后，工具里没法直接刷新看到变化，得去本地文件夹看。右键打开技能目录那个功能，我试了好几次都没反应，应该是 bug。

但怎么说呢，瑕不掩瑜。

我始终觉得，AI 工具的下一站，不是更聪明的模型。

模型已经够聪明了。

下一站，是谁能帮普通人把 AI 干的活管理好。任务面板、标签系统、状态筛选，这些东西听起来不性感，但它们才是让你愿意每天打开这个工具的原因。

Craft Agent 至少让我看到了这个方向。
