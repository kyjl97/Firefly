用手机操控电脑终端，这事以前要么折腾 SSH，要么忍着 TeamViewer 的笨重。现在 UU 远程一个功能就解决了——**手机直接打开电脑的 cmd 终端**，丝滑敲 CLI。

这意味着你可以在手机上随时随地用 Codex、Claude Code 这些命令行 AI 工具，真正把开发环境装进口袋。

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/cover-uu-remote-v1.webp)

### 准备工作

手机和电脑都下载 UU 远程：
- 电脑版：https://uuyc.163.com/
- 手机版：各应用商店搜"UU远程"

### 操作步骤

1. 两个设备登录同一账号
2. 电脑上打开 UU 远程
3. 手机底部「我的设备」就能看到在线电脑
4. 点击「更多 → 终端」，直接弹出电脑的 cmd 窗口
5. 然后就跟在电脑前一样，自热语言对话就行

### 实际体验

延迟很低，几乎无感。手机上打字虽然不如键盘快，但应对 CLI 这种短命令场景完全够用。对于需要临时调个代码、跑个脚本、或者在外面想看看训练进度，这个方案比背着笔记本出门方便太多。

目前唯一槽点是只支持 cmd，对习惯 PowerShell 或 WSL 的用户不太友好。不过既然是刚出的功能，后续大概率会支持更多终端类型。
