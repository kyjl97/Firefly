### 核心能力速览

在动手之前，先花一分钟搞清楚 WorkBuddy 到底能干什么。它不是又一个聊天机器人，而是一个能**真正帮你干活**的 AI 工作台：

| 能力 | 说明 | 举例 |
|------|------|------|
| 自然语言下达任务 | 一句话描述需求，自动拆解执行 | "帮我生成本周工作周报" |
| 自主规划执行 | 自动拆步骤、读写文件、运行命令 | "分析这份销售数据并出图表" |
| 多模态处理 | 文档、表格、PPT、数据分析、图片视频生成 | "根据大纲做一份 10 页 PPT" |
| 本地文件操作 | 读取授权文件夹，批量处理 | "把这 100 张图片按日期重命名" |
| 多任务并行 | 同时跑多个任务，互不干扰 | 边写周报边做数据分析 |
| 连接器生态 | 原生对接微信、邮箱、腾讯文档、Notion 等 | "查我邮箱最近的邮件" |

**与传统 AI 对话的核心区别**：

| 维度    | 传统 AI 对话  | WorkBuddy            |
| ----- | --------- | -------------------- |
| 交互方式  | 只能对话、提供建议 | 实际执行任务               |
| 文件操作  | 需要手动操作    | 自动操作本地文件             |
| 任务复杂度 | 单步骤简单任务   | 多步骤复杂任务              |
| 交付物   | 输出文字回复    | 交付可验收的结果（文档/PPT/代码等） |

### 三种工作模式

WorkBuddy 提供三种工作模式，按需切换：

| 模式 | 一句话理解 | 适用场景 |
|------|-----------|---------|
| **Craft（你说我做）** | 立即行动，直接执行 | 日常任务首选：写文档、做 PPT、分析数据 |
| **Plan（先想后做）** | 先出方案，确认后执行 | 复杂项目：建网站、大型重构、不确定方案时 |
| **Ask（只聊不动手）** | 只回答不操作 | 咨询评估：对比方案、了解信息、代码审查 |

**使用建议**：90% 的日常任务用 Craft 模式即可。遇到复杂需求拿不准时，切 Plan 让它先出方案；只想咨询不动文件时，切 Ask。

### 界面导览

打开 WorkBuddy 后，界面分为三大区域：

- **侧边栏（左侧）**：任务列表按文件夹分组，支持搜索和筛选。底部是用户头像和设置入口。
- **对话区（中间）**：核心交互区域。顶部是任务标题栏，中间是消息列表（你的消息 + AI 回复），底部是输入框，支持上传文件。
- **结果区（右侧）**：展示任务产物。包含四个视图——「产物」查看生成的文档/PPT等，「全部文件」列出所有产出文件，「变更」显示文件修改记录，「预览」实时预览网页/PPT等。

> 💡 **新手提示**：右侧结果区是 WorkBuddy 区别于普通 AI 聊天的关键——你不仅能看到回复，还能直接拿到可下载、可使用的成品文件。

### 专家·技能·连接器
WorkBuddy 连接器，一键打通外部服务，让 AI 能力不再局限。

### 导入skills技能

我自己有个中央仓库
C:\Users\Administrator\AISkills，里面有几百个技能

通过创建目录软链接就可以把AISkills给WorkBuddy使用。

执行前需要先处理一个问题：
**`.workbuddy\skills` 这个空文件夹必须先删除**，因为 `mklink` 要求链接路径不能已存在。

```
:: 1. 先删除空的 skills 文件夹
rmdir "C:\Users\Administrator\.workbuddy\skills"

:: 2. 创建符号链接（让 .workbuddy\skills 指向 AISkills）
mklink /D "C:\Users\Administrator\.workbuddy\skills" "C:\Users\Administrator\AISkills"
```

在这个步骤中：

```
.workbuddy\skills  →→→  AISkills
   (符号链接)            (真实目录)
```

| 路径                                         | 角色                      |
| ------------------------------------------ | ----------------------- |
| `C:\Users\Administrator\AISkills`          | **原始真实目录**（已有你的技能文件）    |
| `C:\Users\Administrator\.workbuddy\skills` | **符号链接目录**（指向 AISkills） |

像WorkBuddy这类图形化Agent，在技能调用的交互设计上非常人性化：你可以**先完整写完需求（比如 “推特上查询最新 Agent 进展”），再从技能列表中点选 `web-access` 这类工具触发调用**。

而不是像 Claude Code 那样先输入斜杠触发指令，再回头补充需求。这种「先写需求，后挂技能」的模式，从根本上避免了指令发送不完整、误操作触发无效调用的问题。

### 实战案例

> 以下案例均为实际使用中验证过的场景，附带原始指令和预期产出，可以直接复制使用。

#### 案例 1：查看邮箱最近消息

连接 QQ 邮箱连接器后，直接在对话区输入：

```
获取我邮箱里的最新 10 封邮件，按时间倒序排列，列出发件人、主题和摘要。
```

WorkBuddy 会自动调用邮箱连接器，拉取最新邮件并在结果区生成结构化列表。比打开邮箱客户端逐封翻看快得多。

#### 案例 2：批量创建金山文档

我最近在整理客户案例，计划在金山文档建一个 "客户案例" 文件夹，要收集 100 个案例，每个客户单独建一个文档，还得给每个文档预填统一的模板框架。要是手动一个个创建、命名、填模板，少说也要花大半天。但用 WorkBuddy 的金山文档连接器，我只需要说清楚需求，它就能一次性帮我生成好 100 个按 "客户 001 - 张山、客户 002 - 李明" 规则命名的文档，每个文档里都提前填好了模板框架，我只需要专注写内容就行，完全不用在重复操作上浪费时间。

```
在金山文档的「客户案例」文件夹下，创建 100 个文档，命名格式为「客户001-张三」到「客户100-李四」，
每个文档预填以下模板：
## 客户基本信息
- 公司名称：
- 联系人：
- 联系电话：
## 需求描述
## 解决方案
## 实施效果
```

#### 案例 3：数据分析与可视化

手上有一份 Excel 销售数据，包含日期、产品、区域、销售额等字段，需要快速出一份分析报告。

```
上传文件后输入：
分析这份销售数据，按月汇总各产品线的销售额，生成柱状图和趋势折线图，
找出销售额 Top 5 的区域，最后输出一份包含图表的分析报告（HTML 格式）。
```

WorkBuddy 会自动读取 Excel、清洗数据、生成图表，最终在结果区产出一个可预览的 HTML 报告，包含交互式图表。整个过程不到 1 分钟。

#### 案例 4：从大纲生成 PPT

需要做一份产品介绍 PPT，只有大纲思路，不想手动排版。

```
根据以下大纲制作一份 15 页的 PPT，风格简洁商务，配色用深蓝+白：
1. 封面：产品名称 + Logo
2. 目录
3-5. 行业痛点分析（3 页）
6-9. 产品核心功能介绍（4 页，每页一个功能）
10-12. 竞品对比（3 页）
13. 商业模式
14. 团队介绍
15. 联系方式
```

WorkBuddy 会调用 PPT 生成能力，自动排版、配图、统一风格，最终产出一个可直接下载的 .pptx 文件。比手动在 PPT 里拖拽效率高 10 倍。

#### 案例 5：Notion 页面搜索与创建

需要在自己 Notion 里查找历史笔记，并基于查找结果创建新页面。

```
搜索我 Notion 里所有包含「重装系统」的页面，按最近编辑时间排序，列出标题和摘要。
```

WorkBuddy 通过 Notion 连接器执行语义搜索，几秒内返回所有匹配页面。接着可以继续指令：

```
在我的 Notion「写作」页面下创建一个「WorkBuddy 保姆级入门教程」文档大纲，
包含认识产品、安装准备、界面导览、工作模式、实战案例等章节。

一句话完成搜索→整理→创建全流程，无需在 Notion 里手动翻找和新建。

#### 案例 6：批量文件处理

下载了一堆图片，文件名乱七八糟，需要按拍摄日期批量重命名并归类到不同文件夹。

```
读取 D:\Photos\2026 目录下的所有图片文件，
按 EXIF 信息中的拍摄日期重命名，格式为 20260601_153000.jpg，
然后按月份归类到子文件夹中（如 2026-06/）。
```

WorkBuddy 会读取每张图片的 EXIF 元数据，批量执行重命名和移动操作，最后在结果区输出处理日志。几百张图片几秒搞定。

#### 案例 7：自动化定时任务

需要每天早上自动汇总前一天的工作邮件并发送到自己的微信。

```
创建一个自动化任务：
- 每天 早上 9:00 执行
- 获取我邮箱过去 24 小时的邮件
- 按重要程度分类汇总（发件人、主题、摘要）
- 通过微信助手发送汇总消息给我
```

WorkBuddy 支持创建定时/周期自动化任务，设置好 rrule 规则后，每天到点自动执行，无需人工干预。适合定时提醒、日报周报、定期巡检等场景。

> ⚠️ 注意：自动化任务执行时电脑需要保持开机状态。

#### 案例 8：ima 知识库 & 腾讯文档读写

通过 ima 知识库连接器和腾讯文档连接器，可以实现跨平台的知识检索和文档操作。

```
1. 从我的 ima 知识库中搜索关于「产品方法论」的笔记
2. 将搜索到的内容整理成一份结构化文档
3. 保存到我的腾讯文档中，命名为「产品方法论整理」
```

WorkBuddy 会先调用 ima 连接器检索知识库内容，然后自动整理归纳，最后通过腾讯文档连接器创建文档并写入内容。全程一句话驱动，跨三个平台完成操作。

#### 案例 9：深度调研报告

需要对一个不太熟悉的行业做快速调研，产出一份结构化报告。

```
调研 2026 年国内 AI 编程助手市场现状，包括：
1. 主要玩家及产品对比（功能、定价、用户量）
2. 技术趋势分析

### 任务管理

WorkBuddy 的左侧边栏就是你的任务管理中心，掌握几个关键操作能大幅提升效率：

**任务状态一览**：

| 状态 | 含义 |
|------|------|
| 规划中 | 正在分析需求、整理执行思路 |
| 进行中 | 正在执行任务 |
| 已完成 | 任务执行完毕 |
| 失败 | 执行过程出现问题 |
| 待处理 | 等待进一步处理或输入 |
| 已归档 | 已归档供后续查阅 |

**高频操作**：
- **继续任务**：对已完成或失败的任务，直接在对话区补充消息即可在原上下文基础上继续推进，不用从头来过
- **保存到工作空间**：长期项目建议保存到工作空间，可开启多个 Agent 同时协作
- **分享任务**：自动生成公开链接，方便分享给同事查看
- **搜索筛选**：按标题搜索或按状态/日期筛选，快速定位历史任务

### 记忆系统

WorkBuddy 有三层记忆机制，让它能"记住"你的偏好和项目上下文：

| 层级 | 位置 | 作用域 | 用途 |
|------|------|--------|------|
| 云端记忆 | 服务器端 | 所有项目 | 自动学习用户长期画像（只读） |
| 用户级本地记忆 | `~/.workbuddy/MEMORY.md` | 所有项目 | 手动记录跨项目的长期偏好 |
| 工作区记忆 | `.workbuddy/memory/` | 当前项目 | 项目级别的工作日志和长期笔记 |

> 💡 你可以直接跟 WorkBuddy 说"记住我喜欢用深色主题"，它会自动写入记忆文件，下次启动时自动生效。

### 使用技巧与最佳实践

**1. 描述需求的结构化公式**：

```
背景 + 目标 + 具体要求 + 输出格式
```

❌ 差的描述："帮我写个周报"
✅ 好的描述："我是前端开发，本周完成了登录模块重构和 3 个 Bug 修复，参加了需求评审会。帮我生成本周工作周报，Markdown 格式，分「本周完成」「下周计划」「风险与问题」三个板块。"

**2. 善用 Plan 模式处理复杂任务**

复杂任务先用 Plan 模式让它出方案，确认后再执行。避免直接 Craft 导致方向跑偏。

**3. 分步迭代而非一次求完美**

先让 WorkBuddy 出初版，再通过追问逐步细化。比如做 PPT：先出框架 → 确认结构 → 再生成完整 PPT → 最后调整风格。

**4. 充分利用上下文累积**

在同一个任务中持续对话，WorkBuddy 会累积上下文。不用每次都重复背景信息。

**5. 连接器先连再用**

涉及外部服务（邮箱、Notion、腾讯文档等）时，先在「设置-连接器」中开启对应连接器，否则 WorkBuddy 无法调用。
