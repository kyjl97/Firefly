我做了一个完整内容创作工作流。

从选题到发布，一句话触发，剩下的全交给 AI。

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260522142459828.webp)


### 第一步：选题

```
/aihot
↓
看今天 AI 圈有什么热点
↓
/content-topic-generator
基于热点生成 3 个公众号选题（含大纲）+ 2 个即刻选题
```

选题确定后，进入写作。

---

### 第二步：写作

根据文章类型选技能：

| 文章类型                       | 用哪个技能             |
| -------------------------- | ----------------- |
| 软件教程 / GitHub 项目 / AI 工具指南 | /kyjl97-tutorial |
| 观点文 / 行业评论 / 个人感悟          | /khazix-writer    |

`/kyjl97-tutorial` 会自动判断是开源项目还是工具教程，按固定结构输出：

```
引言（痛点 + 价值主张）
↓
准备工作（安装 / 配置）
↓
核心内容（步骤 1/2/3，每步有配图提示词）
↓
常见问题
↓
总结 + 延伸（blockquote 金句 + 吸粉文案）
```

---

### 第三步：全文处理

写完文章，一句话触发，5 个 Agent 并行处理：

```
/ article-pack [文章路径或内容]
│
├─ Agent A → baoyu-article-illustrator（配图 + PicGo 上传）
├─ Agent B → article-cover-16x9（封面，文字直接进图）
├─ Agent C → 撰写标题（3 个爆款风格，回显到对话）
├─ Agent D → x-post（即刻版 + X版，回显到对话）
└─ Agent E → beautiful-slides（HTML 幻灯片）
```

**文章类型自动判断**，配图和封面风格随之切换：

| 文章类型 | 配图风格 | 封面风格 |
|---------|---------|---------|
| 教程类（含代码/步骤/工具名） | infographic（清晰写实） | clean-tech（简洁科技感） |
| 观点类（议论/感悟） | scene（温暖插画） | warm-cinematic（温暖电影感） |

---

### 成本

配图和封面共用同一个后端：**GPT-Image-2**

API 服务由**Apimart**平台提供，访问
https://apimart.ai/register?aff=QVui

- 单价：`$0.005/张`
- 一篇公众号配 3~4 张图 + 1 张封面 ≈ `$0.02~0.025`
- 一美元能生成 200 张，`一个月重度使用不到六块钱`

无水印、支持 16:9、分辨率最高 `1K`，PicGo 自动上传 Gitee 图床。

### 完整流程图

```
你
│
├─ ① /aihot                     → 查今天热点
├─ ② /content-topic-generator  → 生成选题（公众号 + 即刻）
├─ ③ /kyjl97-tutorial         → 写教程类文章
│    或 /khazix-writer           → 写观点类文章
│
└─ ④ /article-pack             → 一站式处理
     │
     ├─ 配图 + 上传
     ├─ 封面（文字进图）
     ├─ 3 个爆款标题
     ├─ 即刻版 + X版文案
     └─ HTML 幻灯片
```

一句话，全文案处理完。
