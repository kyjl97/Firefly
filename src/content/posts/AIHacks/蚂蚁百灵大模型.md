## 接入Qwen Code 

我成功接入了Qwen Code与蚂蚁百灵大模型，以下是完整的配置步骤：

### 配置文件路径

> `C:\Users\Administrator\.qwen\settings.json`

### 完整配置代码

```json
{
  "env": {
    "LING_API_KEY": "你的百灵API令牌",
    "QWEN_CUSTOM_API_KEY_OPENAI_HTTPS_API_OPENAI_COM_V1": "你的百灵API令牌"
  },
  "modelProviders": {
    "openai": [
      {
        "id": "Ling-2.6-1T",
        "name": "Ling-2.6-1T",
        "baseUrl": "https://api.openai.com/v1",
        "envKey": "QWEN_CUSTOM_API_KEY_OPENAI_HTTPS_API_OPENAI_COM_V1"
      },
      {
        "id": "ling-2.6-1t",
        "name": "Ling-2.6-1T",
        "model": "Ling-2.6-1T",
        "baseUrl": "https://api.tbox.cn/api/llm/v1",
        "envKey": "LING_API_KEY",
        "generationConfig": {
          "temperature": 0.7,
          "topP": 0.9,
          "maxTokens": 4096
        }
      }
    ]
  },
  "defaultModel": "ling-2.6-1t",
  "$version": 3,
  "security": {
    "auth": {
      "selectedType": "openai"
    }
  },
  "model": {
    "name": "ling-2.6-1t"
  }
}
```

### 临时bat
```
@echo off
title Qwen Code - 百灵模型

:: 百灵 OpenAI 兼容接口配置
set OPENAI_API_KEY=sk-studio-xxxx
set OPENAI_BASE_URL=https://api.ant-ling.com/v1

where qwen >nul 2>&1 || (echo qwen 未安装 & pause & exit /b 1)
qwen -y
```

### 配置说明

| 配置项 | 说明 |
|--------|------|
| `LING_API_KEY` | 蚂蚁百灵API访问令牌 |
| `QWEN_CUSTOM_API_KEY_OPENAI_HTTPS_API_OPENAI_COM_V1` | Qwen Code 自定义API密钥配置 |
| `baseUrl` | API请求基础地址 |
| `temperature` | 温度参数(0.7)：控制回答的随机性 |
| `topP` | Top-P采样(0.9)：控制词汇选择的多样性 |
| `maxTokens` | 最大生成长度(4096) |

## 接入Claude code

Claude Code 的配置方式因版本而异，`settings.json` 格式可能不兼容。bat 环境变量方式是可靠的。这里提供一个**纯 bat 方案**，同时支持**项目级 `.env` 文件**管理：

---
### 配置文件路径

路径`C:\Users\Administrator\.claude\settings.json`

```
{
  "anthropicBaseUrl": "https://api.ant-ling.com/anthropic",
  "anthropicApiKey": "你的百灵API令牌",
  "model": "Ling-2.6-flash",
  "defaultOpusModel": "Ling-2.6-flash",
  "defaultSonnetModel": "Ling-2.6-flash",
  "defaultHaikuModel": "Ling-2.6-flash"
}
```

我自己的启动不起来,因版本而已

### 全局启动 bat（推荐）

```bat
@echo off
title Claude Code - 百灵模型

:: ========== 百灵配置区（修改这里）==========
set ANTHROPIC_BASE_URL=https://api.ant-ling.com/anthropic
set ANTHROPIC_API_KEY=你的百灵API令牌
set ANTHROPIC_MODEL=Ling-2.6-flash
set ANTHROPIC_DEFAULT_OPUS_MODEL=Ling-2.6-flash
set ANTHROPIC_DEFAULT_SONNET_MODEL=Ling-2.6-flash
set ANTHROPIC_DEFAULT_HAIKU_MODEL=Ling-2.6-flash
:: ===========================================

where claude >nul 2>&1 || (echo Claude Code 未安装 & pause & exit /b 1)
claude --dangerously-skip-permissions --model %ANTHROPIC_MODEL%
```

---

### 自动读取项目 .env 的启动 bat

把 bat 放在**项目根目录**，自动加载同目录的 `.env`：

```bat
@echo off
title Claude Code - 百灵模型
chcp 65001 >nul

:: 加载同目录 .env 文件（如果存在）
if exist ".env" (
    for /f "usebackq tokens=1,* delims==" %%a in (".env") do (
        set "%%a=%%b"
    )
)

:: 兜底：如果 .env 没配置，使用默认值
if not defined ANTHROPIC_BASE_URL set ANTHROPIC_BASE_URL=https://api.ant-ling.com/anthropic
if not defined ANTHROPIC_API_KEY (
    echo [错误] 未找到 ANTHROPIC_API_KEY
    echo 请在 .env 文件或 bat 中配置你的百灵 API 令牌
    pause
    exit /b 1
)
if not defined ANTHROPIC_MODEL set ANTHROPIC_MODEL=Ling-2.6-flash
if not defined ANTHROPIC_DEFAULT_OPUS_MODEL set ANTHROPIC_DEFAULT_OPUS_MODEL=%ANTHROPIC_MODEL%
if not defined ANTHROPIC_DEFAULT_SONNET_MODEL set ANTHROPIC_DEFAULT_SONNET_MODEL=%ANTHROPIC_MODEL%
if not defined ANTHROPIC_DEFAULT_HAIKU_MODEL set ANTHROPIC_DEFAULT_HAIKU_MODEL=%ANTHROPIC_MODEL%

where claude >nul 2>&1 || (echo Claude Code 未安装 & pause & exit /b 1)

echo 当前模型: %ANTHROPIC_MODEL%
claude --dangerously-skip-permissions --model %ANTHROPIC_MODEL%
```

---

### 配套 `.env` 文件（放项目根目录）

```env
ANTHROPIC_BASE_URL=https://api.ant-ling.com/anthropic
ANTHROPIC_API_KEY=你的百灵API令牌
ANTHROPIC_MODEL=Ling-2.6-flash
ANTHROPIC_DEFAULT_OPUS_MODEL=Ling-2.6-flash
ANTHROPIC_DEFAULT_SONNET_MODEL=Ling-2.6-flash
ANTHROPIC_DEFAULT_HAIKU_MODEL=Ling-2.6-flash
```

> 记得把 `.env` 加入 `.gitignore`

---

### 快速切换模型

bat 里改一行就行：
```bat
set ANTHROPIC_MODEL=Ling-2.5-1T
```

或启动时临时覆盖：
```cmd
set ANTHROPIC_MODEL=Ling-2.5-1T && start-claude.bat
```

`settings.json` 路径（`~/.claude/settings.json`）是 Claude Code 早期版本的配置方式，新版主要靠环境变量。bat 方案最稳。

### 配置说明

| 环境变量 (bat)                       | settings.json 字段     | 说明                |
| -------------------------------- | -------------------- | ----------------- |
| `ANTHROPIC_BASE_URL`             | `anthropicBaseUrl`   | 百灵 Anthropic 兼容端点 |
| `ANTHROPIC_API_KEY`              | `anthropicApiKey`    | 百灵 API 令牌         |
| `ANTHROPIC_MODEL`                | `model`              | 默认模型              |
| `ANTHROPIC_DEFAULT_OPUS_MODEL`   | `defaultOpusModel`   | Opus 档位映射         |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | `defaultSonnetModel` | Sonnet 档位映射       |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL`  | `defaultHaikuModel`  | Haiku 档位映射        |
