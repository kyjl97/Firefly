AI 刚帮你写好一份总结，却得手动复制、另存、再上传到网盘；或者看到一个资源链接，得切到迅雷、开远程下载、盯着进度。

只需两步，现在可以直接交给 Agent 办。这篇实测两个接法：一个是让 Agent 用自然语言直接操作你的**夸克网盘**（存 / 找 / 下 / 分享 / 整理 / 总结，一句话搞定）；一个是把**迅雷**变成 Agent 能调度的「远程下载器」（扔个链接就下）。

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260808171514389.webp)

### 夸克网盘skill

用自然语言让 Agent 直接操作你的夸克网盘

**安装方式：**

将下面这段话发给你的任意 Agent。

```
请安装 夸克网盘Skill,并授权账号
技能地址：https://pdds.quark.cn/download/stfile/ssyytvtxsstwsu8uo/quarkclouddrive-1.0.11.zip
```

**使用示例**

- 存内容：「把刚才的总结存到夸克网盘」→ Agent 把内容写成文件上传
- 存本地文件：「把这个 md 文件上传到网盘」→ Agent 上传你指定的本地文件
- 找文件：「找网盘里我和妈妈的合照」→ 返回结果表格 + 可点击链接
- 下载到本地：「把网盘里的《金字塔原理》下载到桌面」→ 存到本地目录
- 分享：「把这个文件生成分享链接」→ 返回分享 URL(私密链接额外给提取码)
- 整理：「网盘里所有带猫的照片整理到一起」
- 总结：「总结网盘里《金字塔原理》的核心观点」


⚠️注意：调用时会把你的原始提问发往夸克做服务质量追踪；Skill 可联网自更新(服务器控制代码)。

### 迅雷云盘MCP

一个**远程下载任务型** MCP，下发链接让迅雷下载

1. 创建MCP。
打开这个地址栏，去创建一个MCP，然后复制链接。
https://pan.xunlei.com/mcp

2. 将下面这段话发给你的任意Agent。
前置必做：迅雷打开并登录，且开启「远程下载」——否则无设备、下载失败。

```
我已经安装了迅雷，并且打开了迅雷、开启了「远程下载」。
请你帮我配置这个 MCP，我的 MCP 服务是：
配置后请列出设备并用一个小文件实测一次下载。
```


![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260808163857901.webp)

把这两个接法放一起看，定位其实很清晰：

- **夸克网盘 Skill** 是你的网盘「操作台」——查、存、下、分享、整理、总结，全用一句话；
- **迅雷云盘 MCP** 是你的「下载调度员」——丢链接就下，不用守着客户端。

串起来就是一条顺手的工作流：AI 产出的东西直接落网盘，网盘里要下载的再派给迅雷。对经常和 AI 一起写稿、攒资料的人来说，这条链路一旦接上，基本就回不去了。
