很多 Windows 用户都有一个共同的问题：桌面越用越乱。

下载文件、临时图片、项目资料、截图、文档……积累一阵子，桌面就只剩下“先放这儿，回头再收拾”。回头通常不会来。

问题不是你不会建文件夹，而是 Windows 原生桌面更像一个平面。文件都堆在一起，缺少一层顺手的整理方式。

以前也有不少桌面整理软件，但有的配置太复杂，有的会把原来的使用习惯全部推倒重来。

最近我发现了一款开源工具：[**DeskBox**](https://github.com/Tianyu199509/DeskBox)。

它不替换 Windows 桌面，也不改变文件原来的位置。它做的是在桌面上增加一层“格子”，让常用文件、文件夹和小工具各归各位。

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260819001144273.webp)

### 先把几个关键设置调好

DeskBox 的功能不少，但第一次用不用全开。先把下面几项调顺手，桌面就能开始变得可控。

**常规：开机自动启动建议打开。**

桌面整理是日常习惯，不是偶尔才打开一次的软件。让它跟着系统启动，才不会整理两天又回到原样。

**文件格子：先整理桌面，再改收纳路径。**

首次安装后，可以点击“开始整理”。它会先预览桌面文件的分类结果，你再决定哪些内容进入对应格子，哪些保留在原位。

后面不合适的地方也可以直接拖动调整，不需要一次把规则定死。

收纳路径我改成了：

```
D:\DeskBox\Administrator
```

这样做的目的不是把文件藏起来，而是让 DeskBox 管理的内容和系统文件分开。后续备份、迁移或清理时，也更容易找到。

**功能格子：按需求开，不要把桌面重新塞满。**

我觉得随机、待办和搜索这三个比较实用。待办适合放当天必须完成的事；搜索是否开启，要看你平时有没有更顺手的工具。

**快捷与交互：先留下最常用的动作。**

默认按一次 `F7` 可以显示或隐藏所有格子。搜索快捷键我没有开启，因为我平时用 Listary。

还有一个容易忽略的设置：悬浮操作里的“更多操作”。我把“添加格子”取消了。这样格子右上角不会一直挂着按钮，桌面会干净很多。

之后如果需要新增格子，可以在系统托盘中右键 DeskBox 图标，再选择新建格子或添加功能格子。

### 系统托盘里有个值得用的功能

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260819001247396.webp)

托盘菜单里有一个“新建文件夹映射”，我觉得很实用。

你选择一个已有文件夹后，DeskBox 会把里面的内容显示到对应格子中。文件还是原来的文件，文件夹也还是原来的文件夹，不是又复制了一份。

这比把所有资料拖到桌面上更合理。比如项目素材、常用文档、下载目录，都可以保留原有路径，再通过一个格子快速访问。

DeskBox 解决的不是“让桌面看起来很酷”，而是给桌面加一层可以持续维护的秩序。先把最常用的内容放进去，用几天，再慢慢调整。系统不是一次设计好的，而是在使用里长出来的。

如果安装、配置或整理逻辑卡住了，也可以找我远程协助，把工具装好、用顺手，再接进自己的日常工作流。
