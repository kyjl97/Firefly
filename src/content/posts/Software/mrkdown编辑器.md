### ColaMD
实时显示 AI agent 编辑状态的 Agent Native 编辑器

https://github.com/marswaveai/ColaMD

### Moraya
开源 Markdown AI Agent

https://github.com/zouwei/moraya

![image.png](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260501170443582.webp)

综合使用体验总结：

两款工具均只支持单个文件导入，不支持文件夹批量导入。且第一款无大纲切换功能。

第一款界面设计精致、内置主题美观，但全程为英文界面；

第二款功能更完善，自带 AI 能力，设置面板拥有 MCP 等丰富自定义配置。
