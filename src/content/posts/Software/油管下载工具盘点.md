### 油管下载命令yoinks
https://github.com/pablostanley/yoinks

安装

```shell
npm install -g yoinks
```

Or try it without installing anything:

```shell
npx yoinks
```

Requires Node 18+. Everything else (yt-dlp, ffmpeg) is fetched or bundled automatically.

Usage

[](https://github.com/pablostanley/yoinks#usage)

```shell
$ yoinks https://youtu.be/dQw4w9WgXcQ    # straight to the format picker
$ yoinks                                 # prompts for a url
$ yoinks --theme light                   # force the light palette
```
