今天给使用 Obsidian 的朋友推荐一款 Chrome 插件——**Obsidian Web Clipper**，可以把网页上的任何内容一键剪藏到你的 Obsidian 知识库。

Chrome 商店直接搜 **Obsidian Web Clipper** 即可安装。

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/cover-obsidian-clipper-20260527-175000.webp)



### 安装与设置

| 资源 | 链接 |
|------|------|
| Chrome 插件 | <https://9lnk.io/tr0g> |
| 开源地址 | <https://github.com/obsidianmd/obsidian-clipper> |

#### 设置语言

安装完插件后，第一件事设置语言：

依次点击 **General → Language**，选择**中文简体**。
![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260526223221463.webp)

#### 模板配置
想简单写，点击 **Default**，笔记位置填写个相对路径，内容属性填写3条：来源、日期、标签。
![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260526224433776.webp)

想复杂点，点击模板 **Default**→导入（右上角），导入模板后把默认模板 Default 删除即可。

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260526223231361.webp)


> 自用模板可关注公众号**得救之道**，回复「clippings」获取。

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260526223319188.webp)

#### 配置 API 解释器

打开**启用解释器**，开启**行为 → 自动运行**，提供商选择 **OpenRouter**。

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260526223338173.webp)

### 剪藏场景

使用前建议先把插件固定到工具栏，后面一键就能用。

#### 整页剪藏

看到一篇好文章想存下来慢慢看？点一下插件图标，再点**添加到 Obsidian**，文章就进库了。

#### 片段剪藏

只想存某几段话？划选文字 → 右键 **Obsidian Web Clipper** → 在页面中打开 → 添加到 Obsidian。
![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260526225434965.webp)


这个插件是Obsidian出品的，整体在电脑网页阅读场景做剪藏，非常丝滑，不仅仅是任何文章内容，还可以划选文字。

但是有个问题，他剪藏的X推文链接不完整，我借助的插件是XViral Monitor可以直接复制推文mrkdown
![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260526230246894.webp)
