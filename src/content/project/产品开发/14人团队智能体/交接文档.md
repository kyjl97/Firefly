六、常见问题与排查（给新对话的指令）
========================================
【场景 1：飞书突然不回话】
- 原因 90%：某会话被长任务卡住（持久化状态，重启/重部署都清不掉）
- 排查：① curl https://github.com/kyjl97/eve/v1/lark 测 webhook 是否在线
        ② vercel logs <最新部署URL> 看 lark 请求是否到达
        ③ DeepSeek 余额（api.deepseek.com）
- 解决：让用户【新建一个全新群】拉机器人测试（新会话立即恢复）
  - 不要浪费时间清旧会话（reset 需短期 OIDC，调不通）
  - 重任务提醒用户拆小步骤发指令

【场景 2：配置问题】
- 看 .env.local 是否含所需变量 → vercel env ls production 看云端
- 改密钥后：同步改 .env.local + Vercel → 重新部署
- 公众号/Typefully 若云端报 invalid ip：Vercel 出口 IP 动态，需固定 IP 代理（WECHAT_PROXY）

【场景 3：让 AI 部署/改代码】
- 打开项目目录，先读交付文档和踩坑日志了解上下文
- 改完：pnpm run fix && pnpm validate（必须 0 错误）→ vercel deploy --prod --yes
- eve 的 nitro 构建：vercel.json 不能配 functions.maxDuration（会报错）
- 生图工具不要重新加回云端（会卡会话，已踩坑）

【场景 4：加新角色】
- eve 是"目录即角色"：agent/subagents/<id>/ 放 agent.ts + instructions.md + tools/
- 详见交付文档第 11 步
