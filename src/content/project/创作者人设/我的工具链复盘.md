## 复盘目的

这份清单不只是记录我安装了什么，也要看每个工具处在业务的哪个环节，是否真的在使用，有没有带来内容、收入或可复用资产。

当前主线：

```text
客户问题／AI热点
→ AI工具分析和处理
→ Obsidian整理素材
→ Skill生成脚本、标题、封面和文章
→ 抖音＋视频号引流
→ 微信沟通与成交
→ 连连控远程处理
→ 朋友圈展示案例
→ 飞书、网站和踩坑日志沉淀
```

## 三、素材输入与连接器

### 主要素材来源

1. 客户真实问题、报错截图和远程服务记录
2. AI热点与产品更新
3. 微信群讨论
4. 网页文章、微信公众号
5. B站／YouTube字幕
6. X、即刻和知识星球内容

客户真实问题优先级最高，因为它能同时产生收入、案例和选题。

### 工具

- Obsidian：保存网页、微信内容、字幕和个人思考；输出文章、视频脚本、短文案和朋友圈

- 滴答清单：下一步行动和每日落地清单
- Agent Mail：邮件自动化
- 微信群MCP：群聊信息整理
- jike-web-cli／twitter-cli：即刻与X内容获取或发布
- zsxq-cli：知识星球内容管理

|环节|主要任务|输出|

每次复盘记录主力Skill，不再只统计安装数量。

## 六、沉淀与复用

- 个人品牌网站：公开文章和长期搜索资产
- 《GPT应用实战手册》：现有产品
- 客户交付SOP：报价、远程、验收和售后

## 七、工具分级规则

- P0 主力：每周都用，直接影响内容、收入或交付
- P1 辅助：特定任务使用，作用明确
- P2 备用：主力工具解决不了时使用
- P3 测试：正在观察，不进入正式工作流
- 暂停：30天内不投入维护时间

## 八、每月复盘问题

1. 这个工具最近30天用了几次？
2. 它进入了哪条真实工作流？
3. 它帮我节省了多少时间？
4. 它是否带来内容、收入或可复用资产？
5. 停用后会不会影响主业务？
6. 是否存在功能重复、成本更低的替代工具？

答不上来的工具先放入测试或暂停区，不再继续投入配置和维护时间。
