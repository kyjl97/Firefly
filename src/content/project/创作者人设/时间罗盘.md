# 我的时间规划

## 当前目标

稳定现金流，把重复服务逐步标准化，同时持续用短视频获得新咨询。

安排时间时只看三类事情：今天能收费的事，能带来下一位客户的事，能让我以后少重复劳动的事。

## 每周时间比例

以每周40小时工作时间为参考：

|工作|比例|每周时间|具体内容|
|---|---:|---:|---|
|短视频生产与发布|30%|12小时|选题、脚本、拍摄、剪辑、发布|
|客户服务与订单|30%|12小时|远程安装、报错处理、账号和Plus协助|
|微信咨询与朋友圈|15%|6小时|判断需求、预约、案例和成交|
|手册销售与优化|10%|4小时|介绍、答疑、交付和反馈|
|流程与案例沉淀|10%|4小时|话术、HTML、交付清单、踩坑日志|
|新工具学习|5%|2小时|只研究与客户问题或内容直接相关的工具|

这是一份校准表，不是必须按分钟完成的考勤表。每周复盘时看实际时间是否严重偏离即可。

## 每天的基本节奏

### 上午：内容生产

```text
09:00—09:30  查看咨询，从近期订单中找选题
09:30—10:30  写2—3条短视频脚本
10:30—11:30  集中拍摄
11:30—12:00  剪辑、发布或处理无需远程的订单
```

普通远程服务尽量不安排在上午，避免一个报错打碎整块内容时间。

### 下午：收费服务

```text
14:00—15:00  第一位远程客户
15:30—16:30  第二位远程客户
16:30—17:30  GPT Plus协助、手册交付或临时订单
17:30—18:00  收款、验收、记录问题和结果
```

一天通常最多安排两场远程服务，中间留出缓冲。50元安装或单个报错预留45—60分钟，超出范围就说明情况并重新安排，不无限延长。

### 晚上：咨询与沉淀

```text
20:00—20:30  发一条朋友圈案例或实用内容
20:30—21:00  回复咨询、预约第二天服务
21:00—21:20  记录当天值得复用的问题
```

晚上原则上只沟通和预约，不临时开始普通远程服务。

## 一周节奏

|时间|重点|
|---|---|
|周一|整理选题、集中制作短视频|
|周二至周五|上午内容，下午客户服务|
|周六|处理积压订单，整理一周案例|
|周日|半天复盘，至少半天完全休息|

公众号保持每周一篇即可，从本周咨询最多的短视频话题中扩写，不另起一套选题。B站暂不要求稳定更新；有余力时把3—5条短视频整理成一条合集。

## 五条时间原则

1. 上午优先保护内容生产时间。
2. 普通远程服务集中到下午，一天通常不超过两场。
3. 新工具学习每周最多2小时，客户问题需要时除外。
4. 每个订单结束后，花10分钟记录问题、结果和可用素材。
5. 每周至少半天完全休息，临时服务不侵占睡眠。

## 每周复盘只看这几个数字

- 发布了多少条短视频
- 有多少人私信或加微信
- 收到多少个有效问题截图
- 各类服务分别成交多少单
- 远程服务平均用了多久
- 哪个案例可以继续做成文章或视频

播放量可以看，但咨询量、成交量和单次服务耗时更接近真实结果。
