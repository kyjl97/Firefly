# 我的渠道和朋友圈打法

## 当前成交链路

```text
抖音／视频号发布1分钟竖屏短视频
→ 用户私信或加微信
→ 微信沟通并判断需求
→ 50元远程安装、排错或账号协助
→ 158元GPT Plus相关协助／128元实战手册
→ 朋友圈展示真实过程和结果
→ 新客户继续咨询
```

短视频负责被发现，微信负责沟通，朋友圈负责建立信任，远程服务完成第一次成交，手册和其他协助提高单个客户价值。

## 渠道优先级

|优先级|渠道|作用|当前做法|
|---|---|---|---|
|P0|抖音、视频号|获取咨询|稳定发布1分钟竖屏视频|
|P0|微信私聊、朋友圈|信任与成交|每天维护，真实记录服务|
|P1|公众号|深度内容和长期资产|保持每周一篇|
|P2|B站|教程合集和搜索流量|暂不单独生产，有余力再做合集|
|P3|即刻、推特|低成本同步|有合适内容顺手发，不单独创作|
|暂停|小红书|账号目前被封|保存通知并按正式入口申诉，暂不投入内容时间|

不为每个平台分别准备一套内容。主线跑稳以前，其他平台不能抢抖音、视频号和微信的时间。

## 朋友圈目前要解决的问题

现有朋友圈已经有真实聊天、收款、远程结果和客户反馈，信任证据是够的。问题是晒单较多，新好友未必马上看懂我具体能解决什么。

所以保留晒单，但每条案例尽量补齐三件事：客户遇到了什么、我做了什么、最后有没有验证成功。

## 每10条朋友圈的内容比例

|类型|数量|内容|
|---|---:|---|
|真实服务案例|4条|问题、处理过程、结果|
|实用技巧与避坑|3条|安装、配置、报错判断|
|个人过程与思考|2条|学习、测试、工作现场|
|服务或产品介绍|1条|价格、范围、购买方式|

一天发1—2条即可，不需要为了凑数量连续发收款截图。

## 服务案例模板

```text
今天处理了一个【具体问题】。
客户之前已经尝试过【做过什么】，但还是【现象】。
我远程检查后发现，问题主要在【根因或关键位置】。
处理完成后，我们现场测试了【验证动作】，现在已经【结果】。
如果你也遇到类似情况，可以先把报错截图发我，我帮你判断是否需要远程。
```

不方便公开根因时，可以只写问题类型和验证结果。聊天截图、账号、订单号、邮箱和其他个人信息必须脱敏。

## 四种可以直接发的内容

### 1. 处理前

> 刚收到一个Codex登录失败的问题。客户已经重复登录多次，我先看一下账号问题还是本地环境问题。

### 2. 处理后

> 最后确认不是账号问题，而是本地配置。调整后重新登录，客户现场验证通过。

### 3. 避坑提醒

> 软件反复安装仍然打不开，不一定要继续重装。先看完整报错、系统版本和依赖环境，通常更快。

### 4. 服务说明

> 普通软件安装和单个报错处理50元起。先把软件名称、系统版本和报错截图发我，我会先判断是否适合远程。

## 一个案例如何重复使用

```text
客户问题
→ 一条朋友圈处理记录
→ 一条朋友圈避坑提醒
→ 一条1分钟口播
→ 同步抖音和视频号
→ 每周挑一个咨询最多的问题扩写成公众号文章
→ 有余力时整理成B站合集或同步即刻、推特
```

每次只研究一个真实问题，再换成不同长度的表达，不为不同平台重复劳动。

## 短视频选题从哪里来

- 客户为什么一直装不上某个软件
- 软件安装完成为什么打不开
- DLL、代理、权限或环境配置问题
- Codex登录、安装、GitHub配置卡在哪里
- 客户自己重复尝试后仍未解决的问题
- 50元服务包含什么，什么情况需要重新报价

不追求与服务无关的泛流量。比播放量更重要的是：私信数、加微信人数、有效问题截图数和最终成交服务。

## 当前执行重点

1. 抖音和视频号稳定更新。
2. 朋友圈从单纯晒单改为“问题＋处理＋验证”。
3. 公众号每周一篇，从短视频和客户问题中选题。
4. B站、即刻和推特只做低成本复用。
5. 小红书先处理申诉，不通过规避规则的方式重新运营。
