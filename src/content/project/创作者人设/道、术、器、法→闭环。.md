# 我的“道、术、器、法”闭环

## 一句话定位

我帮普通用户解决 AI 软件安装、配置和报错问题，也分享 Codex、GPT 等工具的实际用法。

我目前不是在做复杂的企业咨询，主要业务很具体：有人不会安装软件、遇到报错、不会处理账号或订阅问题，我通过远程协助或现成资料帮他解决。

## 当前业务

|服务|价格|方式|
|---|---:|---|
|软件安装|50元|远程协助|
|单个软件报错处理|50元起|远程协助|
|谷歌／Apple ID等账号协助|50元|谷歌通常需要远程|
|GPT Plus相关协助|158元|无需远程|
|《GPT应用实战手册》|128元|无需远程|

其中，50元适合问题明确、预计一小时内能完成的安装或单个报错。涉及环境重装、多个软件冲突、数据恢复等情况，需要先判断范围，再单独报价。

账号、验证码和支付信息由客户本人操作。我提供流程指导和问题排查，不保管密码，也不承诺绕过平台审核或风控。

## 道：我长期想解决什么问题

很多人知道 AI 有用，但真正卡住他们的不是概念，而是：软件装不上、账号不会弄、配置看不懂、报错不知道从哪里查。

我的方向就是把这些具体问题解决掉，让客户先把工具用起来。以后能力和需求成熟了，再逐步增加 Codex、Obsidian、Agent工作流和个人网站等更完整的服务。

## 术：我现在靠什么解决问题

- Windows软件安装与常见环境排错
- 路径、权限、依赖、代理、编码和配置文件检查
- Codex、Claude Code、Skill、MCP等工具的实际使用
- 远程协助中的问题定位、操作验证与客户验收
- 把真实问题整理成短视频、文章、案例和踩坑记录

目前最需要加强的不是继续学更多工具，而是提高判断速度：哪些问题能接、预计多久、50元是否覆盖、什么情况必须停止或重新报价。

## 器：我使用的工具

- Codex、Claude Code等AI工具
- 连连控远程协助
- Obsidian、飞书知识库和本地博客
- Skill、MCP与自动化脚本
- 视频号、抖音、微信公众号和微信朋友圈

现有工具已经够用。以后考虑新工具时，只看三件事：能不能解决真实客户问题，能不能缩短交付时间，能不能形成新的内容或收入。都不能，就先不折腾。

## 法：把零散帮忙变成稳定服务

### 客户服务流程

```text
客户描述问题
→ 收集截图、系统和软件版本
→ 判断是否属于服务范围
→ 说明价格、风险和完成标准
→ 需要时通过连连控远程处理
→ 客户现场验证
→ 收款与交付
→ 脱敏整理为案例或踩坑记录
```

### 内容转化流程

```text
真实客户问题
→ 朋友圈案例
→ 1分钟竖屏口播
→ 抖音＋视频号
→ 每周选一个问题扩写成公众号文章
→ 有余力再同步其他平台
```

### 资料归档

- 飞书：项目模板和交付流程
- Obsidian：个人思考与知识连接
- 本地文件：代码、配置和可运行资产
- 博客／公众号：已经加工完成的公开内容
- 踩坑日志：可跨项目复用的错误与解决方法

## 当前阶段的重点

1. 稳定更新抖音和视频号，用真实问题获得咨询。
2. 控制50元远程服务的时间和边界。
3. 每解决一个问题，至少留下一个案例、话术、清单或选题。
4. 朋友圈除了晒单，也要让别人看懂我能解决什么问题。
5. 继续销售158元协助和128元手册，提高单个客户价值。
6. 暂时不同时恢复所有平台，也不建设过于复杂的系统。

## 用来提醒自己的话

现阶段不用证明我会多少工具。把同一种常见问题稳定解决十次，比再安装十个新工具更重要。
