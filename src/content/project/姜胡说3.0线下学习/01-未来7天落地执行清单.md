# 未来7天落地执行清单

目标：用 7 天把“姜胡说3.0线下学习”从课程资料变成一个能反复使用的内容生产小系统。

## Day 1：选靶心任务

今天只做一件事：选出本周要系统化的任务。

建议靶心任务：

**线下学习内容复利工作流**

它的价值是：你已经有课程、图片、PDF、网页和自己的理解，输入足够丰富；同时输出也很明确，可以转成网页、笔记、短视频、朋友圈、公众号。

### 今天要填

- 这个任务最终服务什么目标：个人品牌、内容增长、产品沉淀、客户信任，还是内部提效？
- 谁会看这些内容：自己、学员、粉丝、潜在客户、社群成员？
- 输出给谁：网站访问者、公众号读者、短视频观众、自己的知识库？
- 什么结果算完成：发布网页、写出文章、拍出视频，还是形成可复用 SOP？

### 今日交付

- 一句话任务定义。
- 一张任务边界表。
- 一个本周不做清单。

## Day 2：梳理输入

今天只管输入，不急着生成内容。

### 输入来源

- 线下课程笔记。
- 网站已有内容。
- PDF 总结和原文。
- 现场拍摄图片。
- 自己听完后的真实感受。
- 社群问题、评论区问题、客户问题。
- 对标内容、爆款标题、爆款开头。

### 输入判断标准

一个素材值得进入系统，至少满足其中一条：

- 它解决了自己的真实问题。
- 它来自用户真实反馈。
- 它能解释一个核心方法论。
- 它能变成一个短视频观点。
- 它能沉淀成以后还会用的卡片。

### 今日交付

- 建一个素材清单。
- 每条素材标注：来源、主题、可输出形式、价值判断。

## Day 3：定义输出

今天把输出形式定清楚。

### 四类输出

| 渠道 | 目标 | 标准 |
| --- | --- | --- |
| 网站 | 系统化展示学习成果 | 结构清楚、视觉协调、能让人快速理解 |
| 短视频 | 引流和表达观点 | 有结果、有情绪、有干货 |
| 朋友圈 | 展示进展和可信度 | 露一点价值，重点展示结果 |
| 公众号/长文 | 沉淀方法论 | 逻辑完整，有案例和行动建议 |

### 今日交付

- 选 3 个具体输出题目。
- 每个题目写清：给谁看、解决什么问题、发布到哪里。

## Day 4：写 SOP

今天写流程，不追求自动化。

### 最小 SOP

1. 收集素材。
2. 判断素材价值。
3. 提炼 3 个主题。
4. 每个主题写出：观点、案例、行动建议。
5. 生成对应渠道版本。
6. 人工审核：事实、语气、结构、风格。
7. 发布或归档。
8. 记录反馈。

### 今日交付

- 一份 Markdown SOP。
- 每一步写清输入、输出和合格标准。

## Day 5：做第一个 Skill 清单

今天只设计 Skill，不急着全做完。

### 本周先做 5 个 Skill

| Skill 名称 | 作用 |
| --- | --- |
| course-material-digest | 把课程资料/PDF/图片整理成主题摘要 |
| content-angle-selector | 从素材中选出最值得发布的角度 |
| multi-channel-adapter | 把一个观点改写成短视频、朋友圈、长文版本 |
| quality-review-gate | 检查事实、结构、风格和是否跑题 |
| feedback-asset-archive | 把反馈沉淀成问题卡、方法卡、素材卡 |

### 今日交付

- 每个 Skill 写一句职责。
- 每个 Skill 写输入、输出、失败时怎么打回。

## Day 6：跑一次完整闭环

今天必须真的产出，不再只整理。

### 跑一条内容

推荐题目：

**为什么学 AI 的目标，不是会用工具，而是搭自己的系统？**

### 输出要求

- 一条短视频脚本。
- 一条朋友圈文案。
- 一段网站/长文可用正文。
- 一张知识卡片。

### 今日交付

- 至少发布或保存 1 个成品。
- 记录这次流程哪里卡住。

## Day 7：复盘和升级

今天只复盘，不新增需求。

### 复盘问题

- 哪一步最省时间？
- 哪一步最容易跑偏？
- 哪一步必须人工判断？
- 哪个 Skill 最值得先做成固定能力？
- 哪个输出最有反馈？
- 哪些内容其实没有必要继续做？

### 今日交付

- 一份 7 日复盘。
- 一版 v0.2 SOP。
- 下周只选一个升级点。

## 本周最低合格线

如果时间不够，至少完成这 3 件事：

1. 写清业务梳理表。
2. 跑通一条内容从输入到输出。
3. 沉淀一张“问题 + 解决方案 + 反馈”卡片。
