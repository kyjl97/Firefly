# 业务梳理模板

这份模板用于任何一个 AI 工作流落地前的业务梳理。原则是：逻辑没梳理清楚之前，不进入技术实现。

## 一句话定义

我要把：

`__________`

这件重复发生的工作，变成一套：

`可复用 / 可审核 / 可迭代 / 可交付`

的 AI 协作流程。

## 最小岗位拆分

一个系统至少可以拆成 4 个岗位。

| 岗位 | 负责什么 | 是否可交给 AI |
| --- | --- | --- |
| 素材整理员 | 收集、分类、初步摘要 | 是 |
| 结构编辑 | 提炼主题、搭框架 | 半自动 |
| 质量审核员 | 检查事实、逻辑、风格 | 半自动 |
| 发布复盘员 | 记录反馈、沉淀资产 | 半自动 |

## 判断是否可以开始实现

满足以下条件再进入技术实现：

- 我知道输入是什么。
- 我知道输出是什么。
- 我知道什么结果算合格。
- 我知道失败时怎么打回。
- 我知道哪些判断必须由我来做。

如果不满足，就继续梳理业务。
