

> 基于自媒体内容生产与AI协作系统构建讨论
> 执行时间：每日使用

---

## 每日流程总览

```
早晨输入 → 上午加工 → 下午输出 → 晚上验证 → 睡前沉淀
```

---

## 一、早晨：输入阶段（30分钟）

### 第一步：找问题（10分钟）

**优先级顺序：**

**Level 1 - 自己的问题（最优先）**
- [ ] 昨天做事遇到的痛点是什么？
- [ ] 最近想尝试什么项目/技能？
- [ ] 什么让你不爽/很爽？
- [ ] 内心有波澜的事是什么？

**Level 2 - 别人的问题（次优先）**
- [ ] 粉丝群/客户问了什么问题？
- [ ] 对标账号评论区有什么痛点？
- [ ] 工作中客户遇到什么困难？

**Level 3 - 优质信息源（补充）**
- [ ] 看到大师在做什么？
- [ ] 书籍/播客有什么启发？

### 第二步：筛选问题（10分钟）

**输入标准检查：**
- [ ] 这个问题让我痛苦吗？
- [ ] 这个问题让我很爽吗？
- [ ] 这个问题让我内心有波澜吗？

✅ 三个至少有一个 → 保留
❌ 三个都没有 → 放弃

### 第三步：记录问题（10分钟）

**问题记录格式：**
```
【问题来源】：自己的/粉丝群/评论区/客户
【问题类型】：痛点/爽点/好奇
【问题描述】：一句话说清楚
【情绪感受】：我为什么有感觉？
```

**工具：** Notion / 知识卡片 / 本地笔记

---

## 二、上午：加工阶段（60分钟）

### 第一步：找答案（20分钟）

**核心原则：只找一个答案**

- [ ] 搜索解决方案
- [ ] 看对标账号怎么解决
- [ ] 问AI（ChatGPT/Claude）
- [ ] 找到后就停止，不要贪多

**为什么只找一个？**
看多了就不行动了

### 第二步：验证答案（10分钟）

- [ ] 这个答案能解决问题吗？
- [ ] 我能执行吗？
- [ ] 有没有漏洞？

### 第三步：套框架（15分钟）

**框架选择：**

**框架A：经典结构**（适合教学类）
```
1. 吸引（开头抓人）
2. 痛点（为什么重要）
3. 解决方案（具体步骤）
4. 结果（预期效果）
```

**框架B：结果前置**（适合炫耀类）
```
1. 结果（先说成绩）
2. 痛点（遇到什么问题）
3. 怎么做的（具体方法）
4. 使用场景（谁适合）
```

**框架C：反常识**（适合观点类）
```
1. 你以为...（大众认知）
2. 实际不是...（打破认知）
3. 实际上是...（真实答案）
```

**AI辅助提示词：**
```
我有一个问题：[问题]
我找到的解决方案：[答案]
请帮我用[框架A/B/C]生成一个短视频文案框架
```

### 第四步：加情绪（15分钟）

**情绪检查清单：**
- [ ] 这条内容对谁说？
- [ ] 对应痛苦点还是快乐点？
- [ ] 我有真实经历吗？
- [ ] 能感受到我的情绪吗？

**情绪表达技巧：**
- 用"我"而不是"你"
- 说具体场景，不说抽象概念
- 带表情和语气词
- 真实感受，不装

**关键：** AI能帮你变清楚，不能替你变真实

---

## 三、下午：输出阶段（90分钟）

### 第一步：选择输出渠道（10分钟）

**四选一，根据目的选择：**

| 渠道 | 目的 | 适合场景 |
|------|------|----------|
| 短视频 | 引流、吸粉 | 想扩大影响力 |
| 朋友圈 | 展示、带产品 | 想成交、想炫耀 |
| 社群 | 价值交流 | 想分享、想互动 |
| 公众号 | 沉淀、引流 | 想深度表达 |

### 第二步：按渠道标准输出（60分钟）

**短视频标准：**
- [ ] 前三秒有反馈（开头抓人）
- [ ] 有结果（数据/成绩）
- [ ] 有情绪（真实感受）
- [ ] 有干货（具体方法）
- [ ] 结尾有互动（提问/引导）
- [ ] 结尾有金句（7-20字）

**朋友圈标准：**
- [ ] 大部分炫结果
- [ ] 露一点价值
- [ ] 附带产品/服务
- [ ] 简短有力

**社群标准：**
- [ ] 干货为主
- [ ] 尽量简短
- [ ] 可直接用
- [ ] 鼓励互动

**公众号标准：**
- [ ] 视频的文字版
- [ ] 结构清晰
- [ ] 有小标题
- [ ] 可读性强

### 第三步：发布前检查（20分钟）

**结构检查：**
- [ ] 结构清晰吗？
- [ ] 逻辑通顺吗？
- [ ] 有没有废话？

**内容检查：**
- [ ] 问题讲清楚了吗？
- [ ] 解决方案可执行吗？
- [ ] 情绪真实吗？

**渠道检查：**
- [ ] 符合这个渠道的标准吗？
- [ ] 目的明确吗？

---

## 四、晚上：验证阶段（15分钟）

### 第一步：看数据（5分钟）

**短视频数据：**
- [ ] 前两秒播放率
- [ ] 平均播放时长
- [ ] 点赞/收藏/评论数
- [ ] 新增粉丝数

**朋友圈数据：**
- [ ] 点赞/评论数
- [ ] 私信咨询数

**社群数据：**
- [ ] 互动情况
- [ ] 反馈情况

**公众号数据：**
- [ ] 阅读量
- [ ] 点赞/在看
- [ ] 新增关注

### 第二步：分析反馈（5分钟）

**有反馈 →**
- 为什么打中？
- 可以复制吗？

**无反馈 →**
- 为什么没打中？
- 下次怎么改？

### 第三步：记录结论（5分钟）

```
【日期】：
【内容主题】：
【输出渠道】：
【数据表现】：
【有反馈吗】：
【为什么】：
【下次改进】：
```

**关键：没有反馈也是反馈**

---

## 五、睡前：沉淀阶段（15分钟）

### 第一步：检查输出质量（5分钟）

- [ ] 问题讲清楚了吗？
- [ ] 解决方案讲明白了吗？
- [ ] 有没有可复用的部分？

### 第二步：制作知识卡片（10分钟）

**卡片格式：**
```
【问题】：一句话描述
【来源】：自己的/粉丝/评论区
【解决方案】：具体步骤
【关键点】：最重要的1-3点
【适用场景】：谁适合用
【验证结果】：有效/待验证
【金句】：7-20字总结
```

### 第三步：存入系统

- [ ] 存入Notion
- [ ] 存入IMA知识库
- [ ] 存入本地笔记
- [ ] 打好标签

**沉淀目的：下次可调用**

## 九、常见问题Q&A

**Q1：找不到问题怎么办？**
A：先做事情，做事就会有痛点。没有痛点就去看别人的问题。

**Q2：找到太多答案怎么办？**
A：只选一个最简单可执行的，看多了不行动。

**Q3：情绪不真实怎么办？**
A：用"我"说话，说具体场景，不装，有感受就说感受。

**Q4：没有反馈怎么办？**
A：没有反馈也是反馈，说明没打中，分析原因，下次改。

**Q5：沉淀太多用不上怎么办？**
A：沉淀是为了下次调用，定期回顾，标签要清晰。

**Q6：系统太复杂怎么办？**
A：从简单开始，先跑起来，再迭代。不要追求完美。

**Q7：AI回答不靠谱怎么办？**
A：AI只是辅助，判断要靠自己。多问几个为什么。

**Q8：每个渠道都要发吗？**
A：根据目的选择，一个内容可以"一鱼多吃"，但要按渠道标准调整。

## 十、执行心态

### 核心原则

1. **测试心态** - 每天测一个点，很开心
2. **只找一个答案** - 看多了不行动
3. **看到好内容马上关机** - 围绕一个点深挖
4. **不追求完美** - 先跑起来，再迭代
5. **输出不是结束** - 而是开始接受反馈
6. **每次都要沉淀** - 变成可复用资产

### 关键话术

- "大事化小，小事化细"
- "拆得足够细，刻意练习"
- "没有反馈也是反馈"
- "AI帮你变清楚，不能替你变真实"
- "做自媒体不是为了成为网红，而是锻炼做成一件事的能力"

## 快速启动指南

**第一天：**
1. 读一遍这个SOP
2. 找一个自己的问题
3. 找一个答案
4. 套框架输出一条短视频
5. 看反馈
6. 沉淀一张卡片

**第一周：**
- 每天重复上述流程
- 周日复盘
- 找到适合自己的节奏

**第一个月：**
- 建立稳定的输入源
- 熟练使用框架
- 形成输出习惯
- 积累30张知识卡片

**三个月后：**
- 系统基本成型
- 可以开始优化迭代
- 沉淀成自己的方法论
