## 第 1 条｜本地跑大模型，卡你的是硬盘不是显卡

```
被一张"8GB 内存跑 2.78 万亿参数模型"的截图吸引，我认真查了一下。

结论先说：我这台电脑跑不了，而且卡住它的不是算力。

128GB 内存 + RTX 4060，单看配置相当够用。可这个引擎压根不用显卡，吃的是存储和系统：
模型权重 1.56TB，加上打包的 100 多 GB，要先腾出近 1.7TB 硬盘——我全盘只剩 280G。
系统只支持 Linux，我的 Windows 连 WSL 都没装。

技术确实让人兴奋，但给普通用户的启示更实在：
想本地部署大模型，先看两样东西——硬盘够不够大、系统搭没搭对，而不是先纠结显卡。
很多"看起来很厉害"的部署，门槛往往卡在你没想到的地方。

想省心体验本地 AI，可以先从 Ollama 跑个 7B/32B 的小模型开始，门槛低得多，也够实用。
```
