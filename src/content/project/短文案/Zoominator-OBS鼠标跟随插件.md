# Zoominator OBS 鼠标跟随插件 · 三平台动态

## 即刻版

```text
🔧 录屏最烦的一件事：观众根本不知道鼠标在哪。

教程、直播写代码、产品演示，鼠标一晃就丢，观众跟着看空气。

最近看到个 OBS 插件 Zoominator，专门解决这个问题。它自动缩放整个场景，让画面中心跟着鼠标走。最妙的是它在场景级别工作，不用对每个源单独配置，装上就能用。

几个让我觉得细节到位的点：

1 智能裁剪
缩放时画面永远盖满画布，不露黑边，对裁切过的源也有效。

2 空闲冻结
鼠标停一会儿画面就稳定不晃，一动又恢复跟随。

3 点击高亮
可选的点击光环效果，演示操作步骤时观众能看清点在哪。

跨平台也做得挺全，Windows 全支持，macOS 开辅助功能权限就行，Linux X11 可用，Wayland 还在等标准化的全局光标方案。

想想挺有意思，以前想要这种效果，得搭摄像头、搞追踪硬件、配一堆虚拟摄像头。现在一个插件，把整套"虚拟摄像机系统"搬进了 OBS。

直播工具的自动化也在悄悄进化，从手动到自动，观众体验就是被这些细节一个个顶起来的。

📎 开源地址：https://github.com/mmlTools/zoominator/
```
