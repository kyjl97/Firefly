# Agent 浏览器自动化 Skill 口播稿

来源：`D:\project2026\fuwari\src\content\01-输入\Bilibili\2026-07-21-一个Skill 让 Agent 自动操作浏览器，告别重复枯燥任务.md`

定位：AI Agent / 浏览器自动化 / Skill 定制 / 重复任务提效

建议标题：一个 Skill，让 Agent 自动操作浏览器

建议时长：约 60 秒

## 口播文案

```text
你是不是也有这种问题：

每天都有一些网页操作，特别简单，但特别耗时间。

比如登录后台、复制数据、下载文件、整理表格。

这些事不是不会做，而是不值得一直手动做。

现在可以换个做法：

给 AI Agent 接一个浏览器自动化 Skill，让它直接操作网页。

比如 Ego Lite 这类工具，可以让 Agent 复用你的浏览器登录状态。

不用每次重新登录，也不用反复折腾验证码。

它还能开多个独立空间。

你正常浏览网页，Agent 在后台执行任务，互不干扰。

更关键的是，重复流程可以沉淀下来。

第一次，让 Agent 跑一遍。

第二次，把流程做成 Skill。

如果流程足够固定，还可以直接生成脚本。

以后只给一个网址，它就能自动采集评论、整理数据、保存成 CSV。

判断一个任务能不能自动化，就看三点：

是不是经常重复？

是不是主要在网页里操作？

结果能不能保存成文件？

如果都满足，它大概率适合交给 Agent。

你也有这种重复网页操作的话，评论区打“浏览器”。

我帮你判断：适合做 Skill，还是直接写脚本。
```

## 结构拆解

### 开头：痛点钩子

```text
你是不是也有这种问题：
明明很多工作都很简单，但每天就是要重复点网页、登录后台、复制数据、下载文件。
```

作用：用具体场景筛选目标用户，避免泛泛讲“AI 自动化”。

### 中间：价值输出

```text
给 AI Agent 接一个浏览器自动化 Skill，让它直接操作网页。
人和 Agent 共用同一个浏览器环境。
登录状态、Cookie、插件、配置都可以复用。
多个 Space 可以并行跑任务。
固定流程可以沉淀成 Skill，甚至变成 0 token 脚本。
```

作用：把原视频的工具能力转成用户能理解的收益。

### 结尾：互动转化

```text
你也有这种重复网页操作的话，评论区打“浏览器”。
我帮你判断：适合做 Skill，还是直接写脚本。
```

作用：评论关键词能筛选出有真实自动化需求的人，方便后续承接 Skill 定制、Agent 工作流和远程排错服务。
