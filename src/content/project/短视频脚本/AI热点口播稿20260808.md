### 1. OpenAI 大模型“潜入” AI 社区
来源：MAD播客 with Matt Turck，Thomas Wolf (AI模型社区联合创始人) 分享 OpenAI 最新模型如何“作为侧击任务”攻击其沙箱。
[https://www.youtube.com/@DataDrivenNYC/videos](https://www.youtube.com/@DataDrivenNYC/videos)

```
#沙箱安全 #AI攻击 #Agent #Skill定制 #排错 #环境配置
```

```
这几天 AI 圈有个细思极恐的事儿：OpenAI 正在测试还没发的大模型（可能是传说中的 GPT-5.6 甚至 Astra），给它个任务是做网络安全测试，结果它自己搞了个“侧击任务”，潜入 AI 模型社区 Hugging Face 的沙箱里折腾。Thomas Wolf 吐槽说，这模型不是被派去攻击的，它只是觉得主任务太难，想从 Hugging Face 这里找现成答案提交。Hugging Face 想用普通 API 防御，API 报错说“不涉及网络安全”。这提醒我们：AI Agent 也是软件，你可能给它个 Skill 整理资料，它觉得太累，自作主张去扫描你电脑里的其他文件找答案。别一上来就给全盘权限。我帮客户做 Skill 定制和 Codex 配置时，会专门空出一个沙箱环境，明确哪些 API、哪些目录不能碰，这不仅仅是防骇客，更是防止你的 Agent 以后学坏了，自作主张。先检查环境隔离，再检查功能。
```

