### 7. AI验收
```
AI能生成页面以后，普通人更容易踩坑
#AI设计 #GPT应用指南 #远程服务 #AI工具 #验收
```

```
AI现在能生成页面、封面、网站原型，但你真的会验收吗？

很多页面第一眼很漂亮，真用起来才发现：按钮没用、手机端乱、文案太空、用户看完不知道怎么联系你。

解决方法不是反复让AI“再高级一点”，而是按目标验收：信息清不清楚，入口明不明显，手机端能不能看，能不能带来咨询。

AI负责生成，你负责判断能不能成交。

如果你让AI生成过页面或封面，可以回去看一眼：它有没有真的帮用户完成下一步动作。
```

### 8. Agent边界
```
AI Agent别急着全自动，先把边界讲清楚
#AIAgent #AI自动化 #远程服务 #AI工具 #工作流
```

```
你想做AI Agent，第一句话是不是“能不能全自动帮我干活”？

全自动听起来很爽，但最容易出问题。它能改哪些文件？什么时候要确认？失败了谁负责？结果怎么检查？这些不清楚，越自动越危险。

正确做法是先半自动：让它整理资料、列计划、生成清单、提示下一步。流程稳定以后，再逐步放开执行权限。

好Agent不是最自由，而是边界最清楚。

你要是准备做Agent，先别急着让它全自动，先把“哪些事必须经过你确认”列出来。
```

### 9. Obsidian模板
```
Obsidian加AI，别先装插件，先把模板搭对
#Obsidian #Obsidian模板 #AI知识库 #AI工作流 #知识管理
```

```
很多人问Obsidian怎么加AI，我一般不会先推荐插件。

因为真正的问题不是插件少，而是笔记太乱。标题随便写，标签不统一，内容没有字段，AI想调用也不知道从哪里开始。

解决方法是先搭模板：素材模板、选题模板、复盘模板、客户问题模板。输入格式稳定，AI才能稳定输出。

Obsidian不是收藏夹，能被AI调用才是资产。

如果你的笔记很多但很难复用，问题可能不是插件少，而是模板还没有把输入固定下来。
```
